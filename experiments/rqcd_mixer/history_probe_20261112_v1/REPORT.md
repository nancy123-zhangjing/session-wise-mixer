# 真实历史与打乱历史：第一件商品及分噪声诊断

## 初步结论

1. 不能说模型完全忽略历史。纯噪声自由生成时，换历史使B0/B1的RQ商品分别改变52.20%/51.79%，NN商品改变46.90%/44.80%；真实历史对MSE有小幅有益作用。
2. 但有变化不等于有效个性化。自由生成第一件时，NN任意目标命中数B0真实/打乱为7/6，B1为12/16；RQ为5/4和7/9。相关自由生成命中差异的配对区间包含零，不支持真实历史已有明显推荐收益，也不能反向断言错误历史更好。
3. 中/高噪声MSE在真实历史下分别小约0.5%-0.9%，用户配对区间不含零；中噪声MRR也有小幅改善。说明历史不是纯粹无效，但收益主要停留在弱向量恢复信号，尚未体现为可靠的高噪声目标识别。
4. 中噪声时，B0/B1去噪MSE从约0.594降至0.306/0.331，目标平均排名却从8.1/7.5变为26.9/25.5，Recall@10从86.13%/88.06%降至69.15%/71.85%。高噪声也出现MSE下降、目标排名变差。这是监督优化与商品区分不一致的线索，而非仅凭高噪声低分作判断。
5. 去噪前向量来自真实目标加噪，含有目标信息，因此不是可部署推荐方案；比较只用于诊断去噪器保留商品身份信息的能力。不能据此直接证明MSE目标错误或潜空间不适配，仍可能涉及欠拟合、泛化、输出尺度/收缩及条件学习。
6. 下一步建议先检查去噪输出的范数/尺度与目标排名退化是否关联，并在固定训练子集上做同样只推理检查，区分训练也学不好与验证泛化差；然后再决定是否用简单判别头检验历史表示。不要据此直接加层、解冻RQ Encoder或改Mixer。

复用B0/R25、B1/R28和原8192条固定验证子集；只推理，无训练。历史置换来自不同用户，真实与打乱条件共享噪声。只考察第一件，不存在推荐前缀。

## 核验与解释范围

真实历史自由生成的第一件RQ预测与前次诊断逐条完全一致；权重前后不变。完整配对区间、每项均值与向量复现最大差见COMPLETE.json；用户聚类bootstrap 2000次，单seed、单置换，未作多重比较校正。

历史影响输出不等于历史有益；高噪声更难本身不等于实现错误；教师加噪输入保留目标信息，不能当作正常推理推荐成绩。排名按全目录潜向量平方距离，等距按商品编号排序。
