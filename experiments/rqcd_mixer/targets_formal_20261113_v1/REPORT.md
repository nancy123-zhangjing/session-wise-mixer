# 连续目标两组正式实验：最终结果与验收

2026-11-13。两组均使用 B1 层内 Mixer、seed 2024、同一 SASRec 教师、同一推荐器与 Mixer 初始权重、同一验证/测试噪声，各占一张 H100。训练均完成 R35/T300；每轮 R5–R35 全量验证，按验证 NDCG@5 选 best，并测试 best 与 R35。两组训练目标分别为纯协同向量（CF）和内容＋协同对齐向量（Hybrid）；均使用去噪 MSE＋0.1×RQ 落地监督。

**观察。** 在同一评测协议下，CF 的最佳点和末端点都明显高于 Hybrid；CF 最佳点测试 NDCG@5 约为 Hybrid 的 3.02 倍。CF 验证最佳点出现在 R9，之后没有再次超过该点，R35 验证低约 15.6%；Hybrid 最佳点出现在 R31，R35 验证低约 7.7%。测试集上 CF 最佳点比 R35 高约 32.6%，Hybrid 高约 1.6%。这些是单 seed 两种目标的结果，不能单凭曲线判断退化的具体原因，也不能将差异单独归因于内容信息本身；两种目标对应的 RQ 预训练空间也不同。

**落地诊断。** CF 最佳点测试中，五个位置的原始量化 SID 直接命中目录的比例约 0.50%–0.57%；R35 约 3.98%–4.35%。最终推荐均经过目录落地与合法性处理，五件商品输出完成率为 100%。因此最终指标不是原始 SID 直接命中率；原始落地仍是值得单独研究的接口问题。

**验收。** 两组各有 31 个全量验证摘要（每节点 71,657 个样本）、31 个不可覆盖验证 checkpoint、35 个 R epoch、30 块合计 300 次 T 更新。best 与 R35 测试均为 53,194 个样本，输出完成率 100%；测试与 checkpoint、准备资产、共享教师和测试噪声的 SHA 绑定一致，best/final checkpoint SHA 复核通过。远端冻结源码复核通过，提交基点 `72e74be3c07ca790f7983004f199d96175ae6472`。两张 H100 作业均为 `SUCCEEDED`，占用随作业终止释放。完整逐节点指标及 SHA 收据见 `FINAL_AUDIT.json` 和 `ACCEPTANCE.json`，大 checkpoint 与预测文件保留在远端共享盘。
