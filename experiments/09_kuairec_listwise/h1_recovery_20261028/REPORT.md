# H1后期退化：R20→R26两组续训报告

2026-10-29。KuaiRec原09划分，seed2024，完整验证集71,657条、4,733名用户；固定R26为主终点。

## 1. 这次回答了什么

**固定编码组在本次实验中保住并超过了R20的推荐效果；本次学习率衰减设置没有阻止退化。** Freeze R26的单列表NDCG@5为0.01036453，相对共同R20提高10.59%；Decay为0.00615930，下降34.28%。

两组都是已有H1码本交互模型。Freeze固定的是已经学到的基础码本、Mixer和商品→SID映射，推荐器内部的SID embedding、Encoder和Decoder继续训练。**Freeze不是移除交互，也不是H0。**

## 2. 重要设置与公平性

两组从同一H1 R20/T200权重完整分叉，保留模型、编码、双优化器动量、R scheduler和进度。父文件SHA为`a672ea4d31be5281c2c24c1c7e774bc27eb7e679ec732181a197b703da890bf1`；两组初始参数和优化器指纹一致，8192条起点商品输出也与旧R20对应输出逐条一致。

| 项目 | 本次实际设置 |
|---|---|
| 主体 | 原H路线DiffGRM＋PSE＋Full Mixer；历史最多50件，输出5件列表 |
| 推荐器 | Encoder 1层、Decoder 4层、hidden256、4头、FFN1024、dropout0.1 |
| 编码 | 4本×256码×64维，Full Mixer 4头，残差系数1，不重新初始化 |
| R训练 | 微批256×累积4，有效batch1024；BF16，clip1，label smoothing0.2 |
| R日程 | 继续原35轮日程和500更新warmup进度，不重新warmup；两组各新增4158次R更新，终点18018 |
| Decay | 2次40T＋3R，到R26/T280；基础码本/Mixer同时衰减 |
| Freeze | 跳过T，不推进T优化器或噪声时钟，只训练6R，到R26/T200 |
| 验证 | 全局beam32、最多32份候选列表、batch32、FP32；R23/R26全量，其他规定节点固定8192条 |

Decay采用预先约定的`原LR × 0.5 × [1 + cos(pi × u/400)]`，`u=200…279`。首次实际LR为5e-6/5e-5，最后一次实际更新为2.092934e-6/2.092934e-5；T280保存的下一步日程值为2.061074e-6/2.061074e-5。它是从R20立即减半再衰减，不是声称原训练全程用了该日程。两组终点R学习率均为0.00016066336。

其余损失、DIGER温度/噪声、数据顺序和阶段种子沿用原设置。R只使用hard SID，不直接使用T的Gumbel噪声。实际配置见[ACTUAL_CONFIG.json](ACTUAL_CONFIG.json)，设置来源见[锁定方案](../../../docs/research/onerec_listwise/H1_LATE_TRAINING_RECOVERY_PLAN_20261028.md)和[原实现依据](../../../docs/research/onerec_listwise/IMPLEMENTATION_REFERENCES.md)。

## 4. 对退化原因的提示

Decay两次T块结束、尚未继续R训练时，固定子集NDCG@5分别立即下降10.19%和18.42%。R后续有局部恢复和波动，但到R26仍未保住起点效果。Freeze停止编码更新后，完整验证的R20→R23→R26持续上升。

| Decay编码状态 | 四码位使用数 | 不同SID组合 | 碰撞商品比例 | 交互修正/基础码本范数 | 最近中心重构SSE |
|---|---|---:|---:|---:|---:|
| initial_R20 | 181 / 137 / 190 / 218 | 9,600 | 12.9101% | 0.8237 | 0.744638 |
| T240 | 161 / 122 / 159 / 184 | 9,630 | 12.5000% | 1.1628 | 0.763821 |
| T280 | 144 / 101 / 134 / 158 | 9,643 | 12.3509% | 1.4902 | 0.776524 |

这次码字使用数下降，但SID组合数没有大幅缩小，碰撞比例反而略降；所以**推荐下降不能直接等同于R35那种大面积SID碰撞塌缩**。交互修正继续增大、T后推荐指标立即下降，更值得关注编码持续变化及其与推荐器的适配。它们仍是机制线索，尚未分离码本几何、SID切换、T优化目标和R适应过程各自的作用。

建议下一步优先验证“学到一定阶段后固定编码”的安排能否在预先固定的训练计划、其他seed和时间段上保持收益，再决定怎样调整T目标或更新节奏。本轮到R26结束，没有追加实验。详见[解释边界](INTERPRETATION_AUDIT.md)。
