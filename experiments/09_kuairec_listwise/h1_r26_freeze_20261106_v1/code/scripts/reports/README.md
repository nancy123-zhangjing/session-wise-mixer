# reports：脚本清单

用于由已核验材料生成报告、PDF和报告图片。Stage1旧工具仍依赖archive历史材料，可能直接写既有报告或图；本轮只检查语法/路径，没有运行生成器，不可据此删除历史输入。

所有命令从项目根目录执行，例如脚本路径写成 `scripts/reports/文件名`。历史配方内部的旧源码路径保留原样，不手工改历史锁。
