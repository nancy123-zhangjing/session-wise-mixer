## 事先写下的判读规则（在看结果之前）

1. **旧划分改用 EV 口径后：**
   - 如果 Mixer 增益消失或变负，那么“相反”主要来自换了主指标：Mixer 帮的是命中曝光，不是看完。
   - 如果仍然为正，指标不是主因。
2. **v2 里“看完”和“没看完”的命中差：**
   - 如果 Mixer 多命中没看完的、少命中看完的（多数 seed 同向），就支持“曝光多、看完少”。
3. **在 L5O 里模拟旧划分：**
   - 如果测试落在旧测试时段内的用户 Mixer 差为正、其余为负，或者 ≥72 天减 ≤71 天的对比为正，就是划分构成的问题。
   - 如果各组都一样为负，划分构成不是主因。
4. **按历史长度分组：** 已取消，见下文“短测中发现的设计问题”。改为按目标是否属于当天热门分组：
   - 如果 Mixer 的损失集中在目标属于当天热门的用户，在目标不属于当天热门的用户上持平或为正，就支持“L5O 训练含同期数据、奖励锁定当前热门池”。
5. **类别分解：**
   - 如果中频仍为正、头部为负，就是“L5O 更看重头部”。
   - 如果各类都为负，那就不是测试集权重的问题，而是模型本身变了。
6. **轨迹：**
   - 旧划分冻结后 Mixer 差逐步变大（2025：R20 −30.5% → R35 +15.8%）。
   - 如果 v2 冻结后 Mixer 差在曝光口径上也持平或变小，那么冻结后的训练动态在两轮间不同。可疑的是每遍更新数多 3.2 倍、码本与推荐器的更新比例变了；这只能靠训练对照确认。

每条只对应一种可能的解释，不能单独定论。多条同向才算有力证据。

### 短测中发现的设计问题（已修改；正式运行用 `03c1f7f`，`a48caa6` 只用于测试）

- **历史长度：** L5O 测试用户的历史长度最小 89，5% 分位数已是 128。没有历史 ≤50 的用户，所以历史长度这个角度无法在 L5O 内部检验，只能靠截断历史的推理或训练对照。
- **旧测试时段：** 7,176 人中有 6,844 人的测试开始时间落在旧划分测试时段（2020-08-31 至 2020-09-09）内。两种划分的测试时间基本重叠，“在 L5O 里模拟旧划分”的分组区分不了什么，只保留作记录。
- **两种划分真正的不同：**
  - L5O 的训练集包含其他用户在测试同期的交互；
  - 旧划分的训练完全看不到测试时段。

  因此新增按“目标是否属于当天热门”分组和对应趋势，直接检验这一点。
