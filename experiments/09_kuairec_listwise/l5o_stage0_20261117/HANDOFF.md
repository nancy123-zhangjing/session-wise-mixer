# KuaiRec L5O 首波实验交接

这是供新对话讨论的阶段快照。接手时先读同目录 [阶段报告](WAVE_REPORT.md) 和 [SASRec 校准](SASREC_CALIBRATION.md)。启智即时状态优先于本快照。本对话的 Goal 仍在跟踪两组 TIGER。

## 实验目的与协议

此前全局时间划分的结果与论文量级相差较大，因此使用按用户留出最后、倒数第二个 session 的 L5O 协议，先跑 SASRec 做量级校准，再比较 PSE＋DiffGRM、TIGER、连续扩散＋RQ 三条路线各自有无 Mixer。SASRec 全量测试 Imp Hit@5 0.408445、EV-NDCG@5 0.108858，均通过预设区间，量级校准通过。固定 seed 2024、数据侧历史 128、过滤历史商品，EV 阈值 1.0 为主，2.0 作敏感性分析。最佳点只按验证 EV-NDCG@5 选。

## 如何和旧实验对照

- 旧划分的 H0 Freeze / H1 Freeze 在三个 seed 上观察到 Mixer 提高中频目标命中，旧 TIGER T0A/T1A 也观察到测试增益主要来自中频。这波 H0/H1 未冻结，且 L5O 改了训练频次、目标构成和指标。当前全局分数和单 seed 配对区间不能证明中频收益反转。可用存量预测按 L5O 训练目标频次分桶，优先对照塌缩前同轮 R17 和塌缩后 R34 的目标量、推荐份额、命中率、EV-NDCG 贡献。
- 旧 TIGER 同版同预算的单卡总墙钟为 7.31 / 7.25 小时，L5O 当前推荐阶段记录约 0.20 秒/步，跑满约 11 小时，另计预训练和后续评估。两次的训练更新数、batch、验证步距均相同。历史从 50 改为 128，代码按固定宽度加四件列表前缀槽位，每商品四枚 SID token，再加一个用户 token，训练 Encoder 输入张量宽度由 217 增至 529，PAD 有 mask。这个变化会增加计算，实际耗时差还未做分阶段归因。全量验证样本从 71,657 降至 7,176。
- 旧结果入口为 experiments/09_kuairec_listwise/h_class_profile_20261114/REPORT.md 和 experiments/session_wise_ar/tiger_adamw_20261114/REPORT.md。
