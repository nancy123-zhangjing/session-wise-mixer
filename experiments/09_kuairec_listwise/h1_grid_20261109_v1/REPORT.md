# H1 历史 SID 注意力：A/B/C 对照

A 为已有原 H1 Freeze，B 新增商品内横向注意力，C 在 B 基础上再加同码位跨商品纵向注意力。三组均使用 seed 2024、共同原 H1 R5 起点、R20/T200 冻结 Tokenizer 后继续推荐器至 R35。Grid 属于推荐器，冻结后继续训练。

新增注意力均为 256 维、4 头、Pre-LN 残差，无新增 FFN，输出投影零初始化。原 MLP、Encoder、Decoder 和训练评价口径保持一致。

## 观察与边界

本次配置没有显示出超过原 H1 Freeze 的收益。C 在 R14 曾略高于 A，但优势没有保持；B/C 冻结后仍出现下降和波动，因此不能把这些变化都归因于 Tokenizer 继续变化。B 的最佳点测试优于 C，但 R35 时 C 又优于 B，说明横向与纵向方案的表现也取决于训练阶段。

可能解释包括新增模块的优化难度、额外容量引起的过拟合或交互方式不合适；本实验尚不能区分这些原因。

- B 的 best 测试 NDCG@5 相对 A 的对应比较点为 -6.76%。
- B 的 R35 测试 NDCG@5 相对 A 的对应比较点为 -26.57%。
- C 的 best 测试 NDCG@5 相对 A 的对应比较点为 -12.53%。
- C 的 R35 测试 NDCG@5 相对 A 的对应比较点为 -23.80%。

以上为单 seed 点估计，不能据此断言跨 seed 稳定收益。best 按验证集选择，R35 是固定训练预算对照；两种比较分别解释。C 比 B 还增加了参数量和计算量，差异不能单独归因于纵向注意力拓扑。
