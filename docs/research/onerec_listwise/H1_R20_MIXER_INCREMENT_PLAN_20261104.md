# H1从R20起缩小Mixer新增修正：实验方案

日期：2026-11-04。状态：规划稿；未修改训练代码、未训练、未申请资源。用户选择控制Mixer新增修正，不采用新的学习率衰减实验。

## 1. 研究问题与已有证据

从原H1 R20/T200完整状态出发，保留此时已有编码，只降低随后Mixer相对R20新增输出变化的贡献，能否缓解后期训练扰动与编码塌缩，并保住推荐效果？

原H1、Decay、Freeze/A、D/E均已完成，不重复运行。已有Decay从R20将基础码本与Mixer学习率同时减半并进一步衰减，未保住效果；Freeze固定整个Tokenizer后继续R有效；D/E减少T总量后仍掉分。新的干预仅为有效码本构造中的新增修正系数。

## 2. 精确定义：固定R20锚点，不做逐阶段EMA

原有效码本C(t)=B(t)+M(t)，M(t)包含当前残差系数乘Mixer原始输出，且依赖当前基础码本B(t)与Mixer参数。原残差系数为1。

恢复父checkpoint后、任何新优化器更新之前，保存独立FP32常量B*=B(R20)、M*=M(R20)、C*=C(R20)，形状均为[4,256,64]。常量detach并clone，注册为持久buffer；不能与活参数共享可变存储。

干预的定义：

    C_gate(t) = B(t) + M* + gamma * (M(t) - M*)

便于保证起点数值一致的计算表达：

    C_gate(t) = C* + (B(t) - B*) + gamma * (M(t) - M*)

两者数学等价。此处新增修正指“相对R20的累计差值”，不指每一步候选变化只接受gamma，也不是EMA。锚点全程不更新。

- 起点B=B*、M=M*，所有gamma下有效码本等于C*，不突然移除已有Mixer贡献。
- gamma=1数学上退化为原H1；数值一致性检查时原分支可走原计算路径，不能把浮点表达式等价声称为逐位等价。
- gamma=0固定Mixer修正张量，但基础码本仍学习，因此不是已有Freeze。第一轮不新增此组。
- 基础码本仍按原设置训练。门控同时缩放Mixer输出对基础码本的间接梯度路径；它不是只改变独立Mixer参数而完全不影响基础码本优化。
- 不补偿梯度，不重置Adam，不调整损失权重。gamma会改变前向输出和反向梯度，但不等价于简单将Adam学习率乘gamma。
- 不保证实际SID变动减少gamma倍，也不硬性限制长期漂移；Mixer可能增大原始输出抵消缩放，需要观测。

## 4. 实现边界与最小检查

1. 在统一有效码本函数中实现门控，使T随机可微分配、辅助重建/均衡/锚定损失、确定性SID刷新、碰撞消歧所依赖的码本一致。检查所有调用路径，不能仅评估时门控。
2. R20干预锚点与原损失已有的初始码本anchor是不同对象；不覆盖原anchor，不改原损失定义。
3. 保存gamma、启用标志、B*/M*/C*与父绑定；恢复时不得将当前状态当成新R20锚点。旧checkpoint默认不开门控，保持原行为。
4. 初始有效码本、商品SID必须与父状态一致；用已有固定诊断样本核对起点输出。容许数值检查有明确浮点容差，但不能接受商品SID偷偷改变。
5. 仅做新逻辑相关的检查：gamma=1原行为；起点恒等；门控梯度连通和R/T参数隔离；保存恢复后锚点与下一步一致。无需重复整个旧验收链或多卡测试。

## 5. 对照与评价

主比较：各分支与原H1在相同R/T节点的完整验证结果，以及R35/T400固定终点。原H1有保存的验证结果，不重训。Freeze/A是“继续T是否值得”的性能参照，T总量不同，不能称等T预算对照。Decay只在R23/R26比较其已完成节点。D/E是背景参照，T总量/安排不同。

各新分支在共同候选R20、23、26、29、32、35中按完整验证NDCG@5选择best，R20父状态也纳入，平局取较早节点。两条分支均报告，不仅保留胜者。候选选择为事后设计，应承认单seed与选模边界。

测试仅在设计及验证选模锁定后进行：各分支best与R35，重复checkpoint复用结果。原H1/H0的R35测试未评估，不用验证值代替；本轮默认不新增这些旧端点测试。测试不用于选gamma、停止或修改门控。

训练记录：每个T阶段前、T后、后续每轮R结束，在同一已有8192诊断子集记录推荐指标；训练loss按既有口径记录，不将子集冒充全验证，不将随机T损失与确定性R损失直接比大小。

编码记录：相邻T阶段有效码本位移、相对R20位移、逐码槽/整商品SID变化比例、完整SID碰撞率、四槽利用率。分别保存基础码本变化、原始M(t)、实际使用M*+gamma(M(t)-M*)、新增修正及其范数，避免把原始Mixer变大误判为实际干预无效，也要识别输出补偿。

成功解释分层：
- 起点一致、门控生效是实现正确性，不是研究成功。
- T后扰动减轻、末期编码与验证更稳定，支持稳定性改善。
- 与Freeze接近且几乎不换码，可能只是近似冻结，不能声称持续学习更有效。
- 在稳定且仍有编码变化的情况下超过/接近Freeze，需要结合配对区间判断；跨seed收益仍未验证。
- 编码稳定但推荐仍掉分，说明需检查更新方向、目标冲突与推荐器泛化；不自动追加实验。
