## 0. 一页结论与使用边界

### 0.1 本轮只做哪一个模型

**先训练一个 RQ-VAE 并冻结，再让推荐器在这个固定的潜空间中逐件扩散生成五个商品向量；每件生成结束后，经过目录约束残差量化得到合法 SID，再落地成商品，作为下一件的条件。**

```text
离线商品侧：
既有 BGE-M3 → 既有 PCA256 内容特征 → RQ Encoder → z_i（32维）
                                                    ├─ 固定潜向量表
                                                    └─ 普通残差量化 → 商品 SID 表

推荐侧：
历史 H
  → 连续扩散生成 ẑ_1 → 目录约束 RQ → SID_1 → 商品 î_1
  → 在 H、î_1 条件下生成 ẑ_2 → 目录约束 RQ → SID_2 → 商品 î_2
  → …… → 五商品列表 [î_1, î_2, î_3, î_4, î_5]
```

**改什么：** PSE 换为 RQ-VAE；商品内部直接预测离散码换为生成连续潜向量；历史/前缀输入改为固定潜向量的可训练投影。

**不改什么：** KuaiRec 数据字节、全局时间划分、五商品消费续接任务、最多50件历史、外层逐件生成、商品级相关性定义、不屏蔽历史商品。

**验证什么：** 固定 RQ 潜空间中的条件连续扩散，能否产生可量化、可落地且有推荐价值的五商品列表。

**不同时研究：** Full Mixer、Tokenizer 联合更新、五向量并行扩散、MEDA 重置、额外排序器、多候选搜索、跨 seed 稳定收益。

## 3. 符号、空间和数据形状

| 符号 | 定义 | 维度 |
|---|---|---|
| \(x_i\) | 固定PCA256内容向量 | 256 |
| \(z_i=E_{\rm RQ}(x_i)\) | RQ Encoder输出，量化前潜向量 | 32 |
| \(s_i=Q(z_i)\) | 普通确定性RQ得到的SID | 4个整数，各0…255 |
| \(q_i=\sum_{\ell=1}^{4}e_{\ell,c_\ell}\) | 四层码向量之和 | 32 |
| \(y_i=(z_i-\mu)/s\) | 用于连续扩散的固定缩放潜向量 | 32 |
| \(H\) | 目标前的历史商品序列 | 最多50件 |
| \(j\) | 当前列表位置 | 1…5 |
| \(\tau\) | 连续扩散噪声等级 | 1…1000 |
| R | 完整遍历推荐训练列表一次 | epoch |
| U | RQ预训练优化器更新计数 | 1…60000 |

这里的扩散时间步 \(\tau\) **不是历史实验中的Tokenizer更新数T**。本版下游T更新数恒为0；RQ离线预训练单独记U。

第一版生成的是 \(z_i\) 对应的 \(y_i\)，不是BGE向量、不是推荐器256维hidden，也不是 \(q_i\)。即使两个向量维度一样，也不能视为同一坐标系。

## 4. 阶段A：RQ-VAE预训练规则

### 4.1 结构与参数

| 参数 | 唯一值 | 依据及边界 |
|---|---|---|
| 输入 | PCA256、L2归一化内容 | P：[P3][P4]；避免重新改变内容资产 |
| Encoder | 256→512→256→128→64→32 | P：[P5][P6][P7]；项目现有MLP结构 |
| Decoder | 32→64→128→256→512→256，输出L2归一化 | P：[P6][P7] |
| MLP非线性 | 隐层SiLU；线性层无bias；dropout=0 | P：本地GenRec MLP [P7]；不是TIGER原文ReLU的完全复现 |
| 量化层数／每层码字数 | 4／256 | P：03的4×256；E：保持四位SID接口 |
| 码字维度 | 每层32维；总码本形状[4,256,32] | P：[P5]；L：[L1]支持latent32 |
| 码本归一化／SimVQ | false／false | P：[P5][P6] |
| 第1–3层训练分配 | 最近邻硬前向＋STE反向 | P：[P6][P7] |
| 第4层训练分配 | Sinkhorn分配＋STE反向 | P：[P6][P7]；不是四层普通STE |
| 内容验证／导出分配 | 四层全部确定性L2最近邻，不运行Sinkhorn | P：[P7]的eval路径 |
| commitment系数 | 0.25 | P：[P5]；L：[L1] |
| KL损失 | 无 | P：此处RQ-VAE实现不是另加高斯后验KL的普通VAE |
| 碰撞后缀 | 不增加 | P：03与当前四码接口；区别于TIGER的额外消歧token |

第四层Sinkhorn沿用现有实现：对当前批次距离矩阵按其最大/最小值居中缩放，分母为半极差＋1e-5；均匀行列边际，熵正则0.003、100轮迭代，缩放更新分母加1e-8；内部FP64，按分配矩阵逐行argmax选码。它不保证argmax后严格等占用，也不保证推理最近邻保持相同分配。

不得将训练时的Sinkhorn SID缓存为正式商品SID；所有导出、健康统计和推荐使用eval模式的确定性编码。

### 4.2 初始化

网络采用本地MLP的标准 `torch.nn.Linear` 初始化，seed=2024。码本采用逐层K-means初始化，输入为第一批1024件RQ训练商品对应的潜向量及其残差；PAD、1073件内容验证商品不参与。

K-means每层256中心，无放回抽初始中心；空簇按固定RNG重新选输入向量。为防原工具的无上限循环，本版明确**最多100次迭代，中心最大L2变化<1e-6则停止**，达到上限使用最后中心并记录迭代数。这两个限制是E类工程选择，不是已证明最优值，也不同于旧函数的无上限默认值。

初始化不计入U，不更新神经网络。第一批可用于随后的第1次优化器更新。初始化标志、四层初始中心及RNG状态必须保存；恢复时禁止重新初始化码本。

### 4.3 损失的缩放与梯度口径

对每件商品：

\[
\mathcal L_{\rm RQ}
=\|x_i-\hat x_i\|_2^2
+\sum_{\ell=1}^{4}
\left(
\|\operatorname{sg}(r_{i,\ell})-e_{\ell,c}\|_2^2
+0.25\|r_{i,\ell}-\operatorname{sg}(e_{\ell,c})\|_2^2
\right).
\]

- 重建误差在256维上求和，不先除256。
- 每层量化误差在32维上求和，再对四层求和。
- 最后对批内商品取平均；重建和量化总权重均为1。
- \(\hat x_i\) 是量化向量之和经Decoder并L2归一化的结果。
- 第4层训练中的 \(c\) 为Sinkhorn选码，其余训练层及全部eval层为最近邻选码。
- 残差按本地实现 `res = res - emb_out` 递推，STE的反向路径也沿用；不得只保留前向公式、私自更换残差detach策略后仍声称同一实现。

以上取自[P6][P7]。重建精度不等于推荐质量；RQ预训练不读取推荐验证/测试NDCG。

### 4.4 优化、预算和选模

| 参数 | 唯一值 | 依据 |
|---|---|---|
| 优化器 | AdamW，betas=(0.9,0.999)，eps=1e-8 | P：[P6] |
| 峰值LR | 1e-3 | P：[P5]；不是TIGER的Adagrad 0.4 |
| weight decay | 1e-4，作用于全部RQ可训练参数 | P：[P5][P6] |
| batch | 1024件不同训练商品／更新 | P：[P5][P6] |
| 抽样 | 每更新从9655件中均匀无放回抽1024；不同更新可重复 | P：[P6]；不把U当完整epoch |
| 总上限 | 60,000次优化器更新 | P：[P5]；是沿用的上限，非KuaiRec收敛保证 |
| LR warmup | 600更新，即预算1% | P：[P5] |
| LR后续 | 按60000总更新cosine降至0 | P：[P6] |
| 梯度裁剪 | 全局L2范数1.0 | P：[P6] |
| 精度 | 网络/损失FP32；Sinkhorn内部FP64；TF32关闭 | E：小Tokenizer优先确定性与距离分配稳定；区别于03训练BF16 |
| 内容验证 | 每1000更新，完整1073件，eval batch1024、不丢尾批 | P：[P5][P6] |
| 全目录健康统计 | 同内容验证节点，10728件，不含PAD | P：[P6] |
| 性能早停 | 不启用 | E：完整固定上限轨迹，防临时改预算；安全中断见第12节 |

学习率按“当前将执行的更新编号u，从1开始”设置：

\[
\eta(u)=
\begin{cases}
\eta_{\max}u/W,&1\le u\le W,\\
\frac{\eta_{\max}}{2}
\left[1+\cos\left(\pi\frac{u-W}{U_{\max}-W}\right)\right],&W<u\le U_{\max}.
\end{cases}
\]

本阶段 \(W=600,\ U_{\max}=60000\)。最后一个更新LR为0是上述端点定义的一部分；不得由不同scheduler调用顺序产生一拍偏移。

候选checkpoint须先通过既有健康下限：

1. 每层确定性已用码字数≥64，即最小利用率≥25%；
2. 全目录不同完整SID数≥5364，即不同SID/商品数≥0.5；
3. 权重、潜向量、损失有限。

在合格的U1000、2000、…、60000中，选1073件内容验证平均总损失最低者；精确平局取更早U。完整保留best和U60000。

这两个占用下限沿用[P5][P6]，只是排除严重退化的最低门槛，**不证明碰撞可接受、语义有用或推荐足够好**。碰撞商品比例另算，不能用 `1−不同SID/商品数` 冒充。

若没有合格checkpoint，标记“Tokenizer阶段失败”，不启动推荐器、不自动放宽门槛或换超参数。60,000更新预算没有在KuaiRec验证过，也不承诺运行成本；实际资源预算不够时，应在启动前修订协议，而非运行中暗改上限。

### 4.5 冻结导出

选定RQ best后，在eval模式以FP32导出：

- `z_catalog[10728,32]`：量化前潜向量；
- `sid_catalog[10728,4]`：普通确定性RQ编码；
- `q_catalog[10728,32]`：码向量之和，仅诊断使用；
- 各商品内容重建平方误差；
- 每层码本、商品映射、全目录碰撞桶及排序。

冻结RQ全部参数，设置 `requires_grad=False`，且不放入推荐器优化器；`eval()`本身不等于冻结。导出后为下游全部35R使用同一份表，不根据推荐验证或测试改选RQ checkpoint。

## 5. 固定潜空间的缩放

### 5.1 为什么要缩放

标准高斯噪声的每维方差为1；RQ潜向量尺度则由其预训练决定。直接加单位噪声可能造成信噪比失配。借鉴内容向量扩散中的空间变换思想[L3]，本版只做**可逆的中心化＋全局标量缩放**，不另学投影、不做每维白化。

### 5.2 精确定义

仅使用推荐训练集的目标出现次数 \(n_i\)，共 \(5×709443=3547215\) 次；相同商品按出现次数计权：

\[
\mu=\frac{\sum_i n_i z_i}{\sum_i n_i},\qquad
s=\sqrt{\frac{\sum_i n_i\|z_i-\mu\|_2^2}{32\sum_i n_i}}.
\]

\[
y_i=(z_i-\mu)/s,\qquad
\hat z=s\hat y+\mu.
\]

均值和标量用FP64累计、保存，导出下游FP32表。验证/测试目标不参与拟合；PAD不参与。若s非有限或s≤1e-8，停止，不能通过epsilon掩盖潜空间塌缩。

该变换使训练目标平均每维方差为1，**不是保证每一维都方差1，也不是单位球归一化**。单一正标量便于保留原潜空间的相对欧氏几何；量化始终先逆变换，使用原码本。

历史和生成前缀使用同一张 \(y_i\) 表。PAD=0的输入向量强制全零并由mask屏蔽，不把零PAD代入逆变换或量化。

## 6. 阶段B：推荐器具体结构

### 6.1 条件分解

本版学习：

\[
p(y_1,\ldots,y_5\mid H)
=\prod_{j=1}^{5}p_\theta(y_j\mid H,y_{<j},j).
\]

训练条件中的 \(y_{<j}\) 来自真实目标商品；推理来自已落地商品对应的固定潜向量。公式表示连续生成模型；最终商品分布还受到目录量化、碰撞消歧和去重影响，不能把二者当同一个似然。

### 6.2 网络和注意力

| 模块 | 固定设置 | 依据 |
|---|---|---|
| 历史/干净前缀投影 | 共享Linear(32,256)，有bias | E：统一固定商品输入接口 |
| 噪声目标投影 | 独立Linear(32,256)，有bias | E：避免强制噪声输入与干净输入共用投影 |
| 历史位置 | 50个可学习位置向量，按左PAD后位置0…49 | P：历史50；E：具体位置接口 |
| 目标位置 | 5个可学习位置向量，位置1…5 | P：五件有序标签；E：连续模型接口 |
| 类型向量 | history／clean-prefix／noisy-target三类，256维 | E：区分输入角色 |
| 历史Encoder | 1层、hidden256、4头、FFN1024、GELU、pre-LN | P：层数/宽度来自09；E：新网络的具体pre-LN组织 |
| 去噪Decoder | 4层、hidden256、4头、FFN1024、GELU、pre-LN | P：规模来自09；不是复用离散输出头 |
| Decoder每层 | 因果self-attention → cross-attention到历史 → FFN，均残差连接 | E：清晰保留前缀条件 |
| dropout | attention、residual、FFN均0.1 | P：[P1][P8] |
| LayerNorm | eps=1e-5；Encoder和Decoder各有最终LN | P：eps；E：精确组织 |
| 扩散时间嵌入 | 256维sin/cos→Linear256→1024→SiLU→Linear1024→256 | E：标准时间条件接口，无参数优越性证据 |
| 输出头 | 当前目标token最终hidden→Linear(256,32)，有bias，无输出激活 | E：预测无界连续向量 |

时间嵌入按 \(k=0,\ldots,127\)，频率 \(\omega_k=\exp[-\log(10000)k/128]\)，拼接 \(\cos(\tau\omega_k)\)、\(\sin(\tau\omega_k)\)。只加到当前noisy-target token，不加到历史和干净前缀。

历史Encoder可以双向看**全部已发生历史**，但不接触目标。对第j个训练视图，Decoder输入只有：

```text
[真实目标1的干净向量, …, 真实目标j−1的干净向量, 第j件的加噪向量]
```

不放入第j件的干净向量，也不放入j之后的目标。Decoder因果mask使前缀token不能从当前噪声token反向取得信息，当前token可看所有前缀和自己；cross-attention只访问历史memory。

j=1时只有一个noisy-target token，不需要虚构真实前缀。五个j视图可以展开为B×5个独立视图，但不能将五个噪声目标直接互相开放注意力，后者属于另一种联合列表扩散模型。

### 6.3 初始化和不启用的功能

推荐器从随机初始化开始，不加载原H0/H1/R5权重。新模型内Linear矩阵采用Xavier uniform、bias=0；可学习位置/类型向量Normal(0,0.02)；LayerNorm weight=1、bias=0；attention投影同属Xavier规则。此为E类可复现初始化，不能宣称与旧骨干逐参数同起点。

不使用用户ID embedding、自由item ID embedding、Full Mixer、OCN/CPD、label smoothing、商品CE、对比损失、负采样、CFG、EMA、scheduled sampling或额外重排器。

无CFG意味着训练不随机丢历史条件，推理每个时间步只有一次条件去噪网络调用；不沿用DreamRec的无条件概率0.1和guidance超参数。

## 7. 连续扩散和推荐器训练规则

### 7.1 加噪日程

固定噪声等级数 \(N=1000\)。先在FP64中定义：

\[
f(t)=\cos^2\left(\frac{t/N+0.008}{1.008}\frac{\pi}{2}\right),\qquad
a_t^*=\frac{f(t)}{f(0)}.
\]

\[
\beta_t=\min\left(1-\frac{a_t^*}{a_{t-1}^*},0.999\right),\quad
\bar\alpha_0=1,\quad
\bar\alpha_t=\prod_{v=1}^{t}(1-\beta_v).
\]

**训练和采样都使用截断β之后重新累计的 \(\bar\alpha_t\)**，不能训练用cos解析值、采样用截断后乘积。FP64生成日程，保存FP64原表及FP32运行表。

cosine及0.008/0.999来自[L4]；1000是文献中使用过的量级[L2][L5]，本次选择它避免再引入噪声网格搜索，属于L＋E依据。0.008的原始动机与图像像素尺度相关，不代表RQ潜向量也具有相同理论最优值。

### 7.2 训练标签和损失

每条列表的五个位置均参与训练，权重相同；每个位置独立均匀采样 \(\tau\in\{1,\ldots,1000\}\) 和 \(\epsilon\sim\mathcal N(0,I_{32})\)：

\[
y_{j,\tau}=\sqrt{\bar\alpha_\tau}y_{i_j}
+\sqrt{1-\bar\alpha_\tau}\epsilon.
\]

\[
\hat y_{j,0}=f_\theta(y_{j,\tau},\tau,H,y_{i_{<j}},j).
\]

\[
\mathcal L_{\rm rec}
=\frac{1}{B\cdot5\cdot32}
\sum_{b=1}^{B}\sum_{j=1}^{5}\|\hat y_{b,j,0}-y_{i_{b,j}}\|_2^2.
\]

只预测干净向量，不混合ε/v预测；时间步无SNR额外加权，列表位置无DCG加权。这是DreamRec式目标恢复思想[L2]在固定RQ空间及五位置上的适配，不是DreamRec逐字复现。

所有目标和历史表detach；推荐损失不更新RQ。训练时只采样一个噪声等级做一次去噪预测，**不是为每个训练目标展开1000步反向采样**。

### 7.3 优化器、批量与完整预算

| 参数 | 唯一值 | 设定依据 |
|---|---|---|
| 优化器 | AdamW，betas=(0.9,0.999)，eps=1e-8 | L：[L2]使用AdamW；P：[P8]的betas/eps |
| 峰值LR | **1e-4** | L：[L2]搜索范围包含此值；E：较原离散推荐器1e-3降低一个数量级，避免把CE步长直接搬给新MSE模型 |
| weight decay | 0 | P：原推荐器为0；E：不再加入新的正则强度变量；不是证明MSE无需正则 |
| warmup | 500次推荐器优化器更新 | P：09既有设置 |
| LR衰减 | 以24255总更新cosine降至0，采用4.4同一更新编号公式 | P：原预算时钟；E：迁移到新模型 |
| 梯度裁剪 | 全局L2范数1.0 | P：[P8] |
| 训练精度 | BF16 autocast，参数/optimizer状态FP32；MSE及其归约FP32 | P：原BF16；E：新MSE数值边界 |
| TF32 | 训练与评估均关闭 | E：统一数值边界，不能仅宣称“FP32” |
| microbatch | **128条完整列表** | E：每列表展开5个目标视图，先给显存留余量；未做吞吐/显存验收 |
| 梯度累积 | 通常8次，有效batch1024条列表 | P：原有效batch1024；E：改变microbatch分解 |
| 训练轮数 | 完整35R，无性能早停 | P：预算对照；不声称35R收敛 |
| 模型EMA | 不使用 | E：避免多一套权重、decay及选模选择 |
| 梯度checkpoint/compile | 第一版关闭 | E：先减少实现与恢复复杂度 |

LR=1e-4的依据是**可辩护的起点，不是最优性证明**。固定35R下若仍明显欠拟合，只能报告这一预算内的结果，不能据此否定整条连续路线；本版不自动补跑LR搜索。

每R把709443条训练样本无放回打乱一遍，保留全部尾批。完整有效batch组1024条，最后一组835条：

\[
\lceil709443/1024\rceil=693,\qquad 35\times693=24255.
\]

每个更新组内，microbatch损失乘以 `该microbatch列表数/该组实际列表总数` 后累积梯度。因此尾组7个microbatch（6×128＋67）必须除以835，不得固定再除8。全五位置参与一次组更新，不把一个R误计成五个R。

每R包含3,547,215个目标向量训练视图，但不等于3,547,215次optimizer更新。与原模型保持列表遍历次数和更新数，不等于保持参数量、FLOPs或去噪目标数。

训练只有一个连续阶段：没有“先原DiffGRM暖身5R”，也没有T/R交替；R5只是第一个正式验证节点。

### 7.4 随机性、mask和复现

- RQ预训练、推荐器初始化、训练数据顺序、τ/ε采样、dropout分别使用可保存的RNG流；根seed统一2024。
- 训练每R的数据顺序由协议ID、root seed、epoch派生；调试/验证不消耗训练RNG。
- 衍生seed统一将UTF-8字段以 `|` 连接后SHA256，取前8字节无符号小端整数再模 \(2^{63}-1\)；不使用Python进程随机化的 `hash()`。
- 内容划分仍严格使用2.3已定义的NumPy 2024流，不改为上述hash划分。
- 所有环境版本、确定性kernel选项、实际设备及源码hash写入绑定；设置确定性算法，若算子不支持，暂停审阅而非静默放宽。
- 历史PAD、目标视图padding严格masked；生成接口不接收未来target参数。

## 8. 生成、量化与碰撞消歧

### 8.1 连续采样：每件50次去噪

每件开始于独立32维标准高斯噪声。DDIM η=0，不额外注入逐步噪声。

50个整数等级先按升序定义：

\[
t_k=1+\left\lfloor999\,k/49+0.5\right\rfloor,\qquad k=0,\ldots,49.
\]

推理按倒序1000→…→1使用；之后直接落到干净等级0，且 \(\bar\alpha_0=1\)。这明确避免不同框架的spacing默认值和Python round规则改变端点。

当前等级t、下一等级u<t时：

\[
\hat y_0=f_\theta(y_t,t,\mathrm{condition}),\quad
\hat\epsilon=\frac{y_t-\sqrt{\bar\alpha_t}\hat y_0}
{\sqrt{1-\bar\alpha_t}},
\]

\[
y_u=\sqrt{\bar\alpha_u}\hat y_0+\sqrt{1-\bar\alpha_u}\hat\epsilon.
\]

u=0时直接输出 \(\hat y_0\)。不启用图像库默认的 `clip_sample`、[-1,1]裁剪、dynamic thresholding或向量L2归一化。

η=0只表示给定初始噪声后的轨迹确定，并不意味着模型不随机。每个历史生成一份五件列表，共 **5×50=250次条件去噪Decoder调用**；历史Encoder输出可复用一次。四层Decoder不是4次扩散采样。

50步来自DDIM可跳步方法及论文中使用过的设置[L5]，此处锁定为E类成本折中，不声称在本任务无精度损失。不得运行中看结果不好就改成100/1000步。

### 8.2 目录约束残差量化：主解码规则

先逆变换 \(\hat z=s\hat y+\mu\)。固定商品目录由普通RQ导出的SID构成。

对当前位置j，令 \(S\) 为此前已落地的商品集合，候选商品集合初始为：

\[
C_0=\mathcal I\setminus S,\qquad r_0=\hat z.
\]

依次处理四层 \(\ell=1,\ldots,4\)：

\[
A_\ell=\{s_{i,\ell}:i\in C_{\ell-1}\},
\]

\[
c_\ell=\arg\min_{k\in A_\ell}\|r_{\ell-1}-e_{\ell,k}\|_2^2,
\]

\[
C_\ell=\{i\in C_{\ell-1}:s_{i,\ell}=c_\ell\},\qquad
r_\ell=r_{\ell-1}-e_{\ell,c_\ell}.
\]

每层距离相同取较小码字ID。整个过程为贪心、beam=1，不运行learned分类头，不求全目录最近邻，不声称得到全局最小量化误差。

解释：每层只允许选择“仍有未选商品接得下去”的码字，因此最后SID必在目录中，也能落地为一件尚未在列表出现的商品。历史出现过的商品仍在候选中；只排除本次列表已经选出的商品。

这是**目录约束RQ**，不是未经约束的普通 \(Q(\hat z)\)。它借鉴原09的目录合法性约束[P1][P9]，但由离散概率搜索改成残差距离贪心，属于E类解码适配。

之前讨论中的“无约束量化、无效则PAD”不作为本版正式主解码：原09已带合法性约束，刻意让新模型大量生成空SID会混入明显的落地缺陷。本版不训练第二个模型，而是在同一条受约束轨迹上记录无约束诊断，见8.4。

### 8.3 碰撞桶和前缀反馈

最后的 \(C_4\) 可能有多件商品。按以下顺序取第一件：

1. 该商品固定RQ内容重建平方误差较小；
2. 原始商品ID较小；
3. mapped item ID较小。

这是沿用原09“内容重建误差→原始ID”的规则形式[P9]，但误差来自新RQ重建，不使用旧PSE误差，也不使用推荐热度或未来标签。

同一个SID桶中的不同商品可出现在不同列表位置；只要最终item不同，就不是重复。不能将整个桶当成命中。

将已选商品的**固定 \(y_i\)** 加入前缀，生成下一件。不能用真实目标替换，也不将未落地的任意生成向量无限传下去。

若目录、码本和数值正常且目录至少五件商品，上述规则应产出五件合法互异商品。空候选、非有限距离等属于实现/资产失败：保留PAD作为失败记录，但不得默默用热门商品或ANN补齐，并按第12节暂停处理。

### 8.4 不增加训练分支的解码诊断

对主轨迹中的每个 \(\hat z_j\)，额外计算一次四层无约束最近邻 \(Q(\hat z_j)\)，只保存诊断：

- 原始SID是否存在目录；
- 原始SID是否仍有未选商品；
- 约束SID与原始SID是否相同；
- 首次被目录/去重约束改变的层；
- 原始及约束后的潜空间残差范数；
- 选中SID桶大小和最终item ID。

这些只是**相同生成向量上的局部诊断**，不是第二条“全程无约束解码”的推荐结果，因为后续前缀仍来自主轨迹。不能把它伪装成独立消融。

若约束改写率很高，说明输出接口对结果影响很大；不能因为最终非法率为0就宣称生成器已学会合法SID。

## 9. 验证、选模、测试和统计

### 9.1 主评估必须固定

| 设置 | 规则 |
|---|---|
| 每历史候选数 | 1份完整五商品列表 |
| 排序 | 保留生成顺序；不按量化误差、热度或测试命中重排 |
| 主指标 | 真实商品级NDCG@5 |
| 辅指标 | HR@5、Recall@5、完整列表率、非法/PAD/重复率 |
| 聚合@10/20/50 | 不作为本版指标；只有一份五件列表，不能冒充原32候选池 |
| 正式推理精度 | 网络FP32，TF32关，eval模式，dropout关 |
| 量化距离 | FP32显式平方差求和；相等距离较小码字ID，不用TF32近似距离 |
| 推理batch | 32条历史，不丢尾批 |
| 噪声基础seed | 20241104 |
| 噪声键 | `protocol_id|20241104|split|sample_id|j`，按7.4派生 |
| 噪声生成 | 每个键用独立CPU Torch Generator生成FP32的32维randn，再搬至设备 |
| 验证节点 | R5、8、11、14、17、20、23、26、29、32、35，共11个 |
| 选best | 完整验证样本平均NDCG@5最高，精确平局取较早R |

每个checkpoint对同一样本使用相同初始噪声（common random numbers），减少选模比较中的采样差异。它不代表已覆盖采样方差。锁定PyTorch版本及噪声生成路径，要求不受评估batch/进程切分影响。

对一条输出列表，相关性为预测item是否属于五个真实目标；PAD贡献0：

\[
\operatorname{NDCG@5}
=\frac{\sum_{k=1}^{5}\mathbf1[\hat i_k\in Y]/\log_2(k+1)}
{\sum_{k=1}^{5}1/\log_2(k+1)}.
\]

HR@5表示至少命中一件；Recall@5=命中不同目标数/5。主汇总按列表样本平均，不按用户先平均。

### 9.2 固定终点与正式测试

完成R35和所有正式验证后：

1. 冻结RQ checkpoint、推荐best、推荐R35、完整解码配置及其hash。
2. 正式测试只评估best和R35；若相同，复用同一预测文件。
3. 禁止用测试结果在学习率、采样步数、RQ checkpoint或碰撞规则之间挑选。
4. 不因结果负向自动追加seed、延长R、调学习率或重做Tokenizer。

本项目历史测试结果已被多轮研究看到。即使本轮遵守不使用测试选模，也不能把同一测试集描述为全新、从未接触的盲测。

### 9.3 与已有H0/H1/A/D/E怎样比较

复用已有best/R35报告和保存的逐样本结果，不重跑旧模型或旧统计。主历史参照为旧H0 best，其已报告测试NDCG@5为0.00860706；A best为0.00943079，仅作补充参照[P10]。

必须在结果表显式列出：

| 方案类别 | 单份列表来源 | 候选/选择机制 |
|---|---|---|
| 原H0/H1/A/D/E | beam搜索所得最高分列表 | 原全局beam32 |
| RQCD-H | 一条随机初始噪声轨迹的五商品列表 | M=1，无候选排序器 |

这是**系统级历史参照，不是候选预算对齐的架构因果比较**。不能把M=1和beam32写成“同样beam32”，也不能把50个扩散步当作50个候选。

如后续要声称连续机制优于离散机制，需要另立匹配Tokenizer、冻结范围、参数量、搜索预算等的对照；本版不自动增加这些分支。

### 9.4 置信区间和时间分段

对本版best/R35测试指标，以及它们与已有H0 best的差值，规定2000次用户聚类bootstrap、seed=2024、双侧百分位95%区间。抽用户有放回，每个抽中的用户携带全部样本，分子/分母按抽样后的样本总和计算，主估计仍为样本平均。

比较时按sample_id对齐旧预测；若只有旧汇总而没有可信逐样本文件，差值CI明确缺失，不用独立区间拼配对区间，不重跑旧推理补文件。新旧结果的区间仍不能消除不同搜索预算造成的混杂。

只对本版best保存的验证预测做既定时间分段，切点1598745441188500微秒，前38644／后33013条；比较同段旧H0 best。该切点不是重新划分训练/验证的切点。R35不替代best进入主时间泛化表。

区间不覆盖训练seed、采样seed、选模和事后方案设计的不确定性；分组/多指标区间不做多重校正，应按探索性解释。

## 10. 要保存哪些学习曲线和诊断

### 10.1 不把连续误差当推荐效果

| 层面 | 指标 | 时间点 |
|---|---|---|
| RQ拟合 | 内容验证总损失、重建/量化分项、LR、梯度范数 | 每1000U |
| RQ编码 | 不同SID数、碰撞商品比例、最大桶、各层使用数/熵/perplexity | 每1000U，正式eval分配 |
| 潜空间 | s、z范数/残差分布、非有限值计数 | 导出时 |
| 推荐训练 | MSE、五位置MSE、LR、裁剪前梯度范数、更新数 | 每100更新及每R末 |
| 推荐验证 | 商品级NDCG/HR/Recall、输出完整率 | 正式11个完整验证节点 |
| 落地诊断 | 8.4的原始SID有效率、可用率、约束改写率、各层干预率 | 同完整验证/测试 |
| 输出分布 | 不同推荐商品数、前十推荐份额、训练head/mid/tail/未作目标分组 | 正式best/R35的保存预测，统计分母写清 |
| 固定资产 | RQ参数与z/SID表hash、推荐optimizer参数归属 | 阶段B开始及每R末 |

为了分离“去噪学得怎样”和“商品落地怎样”，另外设置**不参与选模**的teacher-forced验证MSE探针：

- 使用既有固定8192验证sample_id清单[P11]，不另挑“更好看”的子集。
- 真实前缀仅用于该诊断，标签不传入正式生成。
- 固定等级 \(\tau=\{100,500,900\}\)，每样本/位置/等级固定独立噪声。
- 每R1…35结束计算一次，按列表×位置×维度平均；报告明确标“8192条teacher-forced子集MSE”。
- 不用它选best，不用它替代完整验证NDCG，不拿它声称测试期生成质量。

如既有8192清单无法找到或验证身份，先标记诊断入口待解决，不静默换清单；它不阻止先完成文档，但会阻止未来声称此项诊断已经交付。

### 10.2 效率口径

记录训练每更新秒数、有效列表/秒、显存峰值，以及完整验证/测试总耗时。推理计时包含历史编码、250次Decoder调用、目录量化、去重和商品落地。

第一次运行前没有GPU小时或端到端速度实测。不得直接使用旧H1耗时估算为本模型实测；batch32总耗时不能冒充单请求p50。

本版不另增线上latency实验。需要线上延迟结论时，应另定warmup、同步、batch、H2D与索引范围协议。

## 11. 实施前必须通过的最小验收

以下均是**未来新实现的测试要求**，不是要求重跑历史实验，也不是当前已通过的检查。

| 检查 | 必须满足 |
|---|---|
| 资产身份 | 数据/内容/商品行序与绑定一致，PAD不混入拟合 |
| RQ导出一致 | `Q(E(x_i))`与保存SID逐件完全一致；加载checkpoint后无需重新K-means |
| 普通/约束量化接口 | 未排除商品时，对目录真实z_i，约束量化返回与普通RQ相同SID |
| 内容重建消歧 | 同SID桶按新RQ误差/原始ID/mapped ID排序，改变batch不变 |
| 逆变换 | z→y→z的FP32最大绝对误差≤1e-5×max(1,max_abs(z)) |
| 参数隔离 | 推荐训练前后RQ、潜向量表、SID表逐字节不变；optimizer中没有冻结参数 |
| 条件无泄漏 | 固定H、前缀、noisy input和τ时，改变外部当前/未来标签不影响输出 |
| 目标确实参与学习 | 训练样本标签改变会改变监督损失；不能误把“无泄漏”测试变成丢弃标签 |
| 五视图隔离 | j视图不能读取第j件干净向量或未来位置；独立与批量视图前向在关闭dropout时匹配 |
| 时间日程一致 | 训练/采样共用截断β后的累计表；50个等级严格递减且含1000、1 |
| 去噪oracle | 在人工向量上给出真实y0的oracle预测器，DDIM公式恢复误差满足1e-5相对尺度容差 |
| 目录合法性 | 真实/人工碰撞目录均得到5件合法互异item；历史商品仍可被推荐 |
| 梯度累积 | 人工尾组835的加权累积与整组平均梯度在FP32合理容差内一致；不得固定除8 |
| 噪声隔离 | 相同sample_id、位置、split的初始噪声不随batch或评估进程分片变化 |
| 指标 | 已知全命中/全不命中/PAD案例正确；与旧商品级metric实现交叉核对 |
| 数值与恢复 | 新模型真实BF16更新、完整状态保存/恢复通过；预演权重不进入正式初始化 |

Tokenizer健康门槛通过是必要但不充分条件。真正的推荐可行性最终看商品级结果，不设置“必须超过H0才算工程验收通过”的结果导向门槛。

实施不得复用旧脚本的默认自动CUDA训练入口来“顺便试一下”。先完成独立适配和明确授权，再在新输出目录做有限预演；预演与正式训练使用隔离的随机状态和产物。

## 12. 中断、失败、恢复和版本纪律

### 12.1 不按表现临时修改协议

- RQ与推荐器都按固定最大预算运行，不启用性能早停。
- NaN/Inf、数据绑定错误、标签泄漏、冻结参数变化、目录无法完成五件、非确定性算子等安全/正确性问题立即停止并保存证据。
- 推荐指标低、训练MSE下降而NDCG差，是可报告的负结果，不是自动改参数的授权。
- OOM、资源不足或环境不兼容时暂停；不静默减有效batch、减少视图、改采样步数或切成多卡。
- 任何科学参数变化产生新的协议版本；若已经查看测试，再修订必须披露测试反馈，不能伪装成预先锁定。

### 12.2 checkpoint内容

RQ每1000U、推荐器每100更新和每R末保存完整状态；阶段A/B还分别保存best和最终点。

完整状态至少包含：

- 网络参数、优化器、LR scheduler、更新编号、epoch及批次游标；
- Python/NumPy/CPU Torch/CUDA Torch和专用generator RNG；
- 混合精度设置及适用的scaler状态；
- RQ初始化标志；阶段B引用的冻结RQ/表/缩放参数hash；
- 数据排列、当前更新组状态与协议/代码/环境绑定；
- best指标、best点、已完成验证记录。

不在梯度累积半组保存“可精确恢复”checkpoint；只在完整optimizer边界保存。best用于最终评估也要有完整身份，不只保留一个没有配置的state_dict。

恢复只允许恢复同协议、同身份产物；不重置optimizer、噪声时钟或LR日程，不把失败预演接成正式训练。若硬件/库变化，只能声明恢复可用性已验证到实际测试的范围，不声称CUDA逐位一致。

## 16. 本版最终判定

本版已经定下**一个**而不是一组自由搜索方案：

> **固定4×256、latent32的RQ-VAE；外层逐件生成五件；内层1000级连续扩散训练、50步DDIM采样；35R固定推荐预算；目录约束RQ落地；单份列表商品级验证选模。**

其价值是把“固定语义潜空间中的列表连续生成”先做成可解释的系统基线。已有冻结续训不重做，H1稳定性干预不混入；联合RQ训练、并行列表扩散和性能调优均留在本版之外。

当前完成的只是研究设置文档。模型可运行性、数值稳定性、资源成本及推荐效果，均须未来获授权后的实施和实测才能确认。
