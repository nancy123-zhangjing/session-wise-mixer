## 1. 研究问题、决策来源与边界

研究问题：在根据用户历史逐件生成五件推荐商品的任务中，让残差量化码本进行层内或层间因果交互，能否改善整套推荐方法的效果。

首轮固定三组：B0 无 Mixer、B1 层内 Mixer、B2 层间因果 Mixer。每组独立进行 RQ 预训练，再进行推荐器与 Tokenizer 的交替训练。三组共用数据、训练预算、推荐器结构、损失、落地与评测规则。B1 与 B2 的结构和参数量相同，主要区别是注意力可见范围。

## 2. 总体信息流与符号

商品侧：

    固定 256 维内容特征
      → RQ Encoder
      → 32 维量化前向量 z
      → 基础码本＋可选 Mixer
      → 四层残差量化
      → 四位 SID、量化向量 q、SID→商品集合

推荐侧：

    最多 50 个历史商品 ID
      → 查当前 SID 表
      → 四张独立 SID embedding 表
      → 200 个 256 维 token
      → 两层 T5 Encoder：历史表示 H
      → 四层条件扩散 Decoder：历史 H＋已生成商品的 SID 前缀
      → 20 次 DDIM 得到当前商品的 32 维连续向量
      → 目录约束量化＋碰撞桶消歧
      → 一个实际商品
      → 把该商品的 SID 加入 Decoder 前缀，继续，直到输出五件

历史 H 在一次列表生成期间固定，不把新生成商品并入历史重新编码。训练时用真实的先前目标作前缀；推理时用实际落地的先前推荐商品作前缀。

| 符号 | 含义／形状 |
| --- | --- |
| B | 一个逻辑 batch 的 session 数；有效 batch 为 1024，尾批按实数计 |
| N | 本 batch 的目标商品出现次数，N=5B；不是去重商品数 |
| i、u_i | 商品 ID、固定内容向量；u_i∈R²⁵⁶ |
| z_i、q_i | 量化前／四层量化后商品向量，均为 32 维 |
| ℓ、k | RQ 层号 1…4、中心编号 0…255 |
| W^ℓ、C^ℓ | 基础码本、有效码本，各为 [256,32] |
| c_i、c̄_i | 确定性四位 SID、当前 T 块缓存的四位 SID |
| E_ℓ | 推荐器独立 SID embedding 表，[256,256] |
| H | 历史 Encoder 输出，[B,200,256] |
| j | 五件列表中的位置，1…5 |
| t | 扩散噪声等级，1…1000；不代表 Tokenizer 更新次数 |
| u_T、u_R | T／R 优化器各自的累计更新次数 |
| sg(x) | 数值等于 x，但该支路反向梯度为零 |

两种 Decoder 必须区分：**RQ Decoder** 用于预训练重建内容特征；**扩散 Decoder** 用于生成推荐商品的连续向量。联合训练不使用前者，但始终训练后者。

## 4. RQ Tokenizer 与 Mixer

### 4.1 RQ Encoder／Decoder

| 模块 | 层宽 | 激活与规范 |
| --- | --- | --- |
| RQ Encoder | 256→512→256→128→32 | 隐藏层 ReLU；最后线性；不加 BN、dropout 或输出 L2 归一化 |
| RQ Decoder | 32→128→256→512→256 | 隐藏层 ReLU；最后线性；重建输出不强制 L2 归一化 |
| 基础码本 | 4×256×32 | 四层真实残差量化；不是三层 RQ 加一个消歧编号 |

编码维度与 MLP 参考 [TIGER](https://arxiv.org/html/2305.05065v3)，预训练规则参考 [ETEGRec RQ-VAE](https://github.com/BishopLiu/ETEGRec/blob/main/RQVAE/models/rqvae.py)。四层真实 RQ 与加入 Mixer 是本次选择，并非逐项复刻 TIGER。

### 4.2 确定性目录编码

对每件商品，先计算 z_i=Enc_RQ(u_i)，然后：

$$
r_{i,1}=z_i,\quad
c_{i,\ell}=\arg\min_{k=0,\ldots,255}\|r_{i,\ell}-C^\ell_k\|_2^2,\quad
v_{i,\ell}=C^\ell_{c_{i,\ell}},
$$

$$
r_{i,\ell+1}=r_{i,\ell}-v_{i,\ell},\qquad
q_i=\sum_{\ell=1}^{4}v_{i,\ell}.
$$

精确相同距离时选择较小中心编号。目录编码不加 Gumbel、不用 Sinkhorn、不受当前推荐列表去重约束。保存 SID[i,4]、量化向量 q_i、SID→全部对应商品的多值桶和合法前缀索引。碰撞不能靠覆盖一个商品 ID 解决。

### 4.3 两种 Mixer 的共同结构

所有四层共同输入，不给某个用户生成独立码本：

$$
X_{\ell,k}=\operatorname{LayerNorm}(W^\ell_k)+e^{\rm layer}_\ell.
$$

| 参数 | 已定或补全的具体值 |
| --- | --- |
| 层数／头数／宽度 | 1 层多头注意力，4 头，宽度 32，每头 8 维 |
| LayerNorm | 逐中心 32 维；eps=1e-5；共享可学习 scale、bias，初值 1、0 |
| 层标记 | [4,32] 可学习参数；Normal(0,0.02) |
| 中心编号标记 | 不使用；不人为绑定不同层的第 k 个中心 |
| Q、K、V、输出投影 | 四层共享；B1/B2 相同参数结构；补全为带 bias 的线性层 |
| FFN／dropout | 不附带 FFN；注意力 dropout=0 |
| 初始化 | Q/K/V 权重 Xavier uniform、bias=0；输出投影及其 bias 全零 |
| 外层形式 | 只把注意力输出作为修正加回基础码本，不把 X 的残差再加一遍 |

将 X 展成 [1024,32]。每个头：

$$
A_h=\operatorname{softmax}\left(\frac{Q_hK_h^\top}{\sqrt8}+\mathcal M\right),\qquad
U=\operatorname{Concat}_h(A_hV_h)W_O+b_O.
$$

上述缩放是 **Mixer 的普通多头注意力**；第 5 节 T5 使用其自身的实现约定，不混用。

对 query 中心 (ℓ,k)、key 中心 (m,n)，掩码是：

| 组 | 可见条件 | 对应四个层块的可见矩阵 |
| --- | --- | --- |
| B1 层内 | m=ℓ | 对角块可见，其他块屏蔽 |
| B2 因果 | m≤ℓ | 层块下三角可见，包括对角块 |

每个可见块内部的 256×256 个关系全部可见。**不能把展平后的 1024 个中心套普通逐 token 下三角 mask**，那会给同层中心编号添加不存在的先后关系。B2 第一层不直接读取后层，但共享参数及联合损失仍能让不同层的训练相互影响，不能声称前层参数完全不受后层监督影响。

### 4.4 参照第一层校准修正尺度

采用当前基础码本 RMS：

$$
s_\ell=\sqrt{\frac{1}{256\cdot32}\sum_{k,d}(W^\ell_{k,d})^2},\quad
\rho_\ell=\operatorname{sg}\left(\frac{s_\ell}{\max(s_1,10^{-8})}\right),
$$

$$
\Delta^\ell=\rho_\ell U^\ell,\qquad C^\ell=W^\ell+\Delta^\ell.
$$

B1、B2 在预训练和联合训练中都使用同一规则。不另加 0.1 门控，不对输出 U 强制归一化，不增加未约定的裁剪上限。零输出投影使初始 C=W；初期具有非零学习率的更新先改变输出投影，内部 Q/K/V 可能要等输出投影离开零以后才收到非零梯度，这是预期行为。

当 s_1 未触发数值保护时：

$$
\frac{\operatorname{RMS}(\Delta^\ell)}{s_\ell}
=\frac{\operatorname{RMS}(U^\ell)}{s_1}.
$$

因此，这个规则校准各层尺度，**不保证每层实际相对修正严格相同，也不保证幅度小于某个值**。记录每层 W、U、Δ、C 的 RMS 和 Δ/W；异常接近零或非有限的尺度必须报告，不能靠 epsilon 掩盖。

## 5. 独立 SID embedding 与历史 T5 Encoder

### 5.1 商品 ID 如何成为 200 个 token

四张独立参数表 E_1…E_4，每张 [256,256]。第 ℓ 码位编号 k 查询 E_ℓ[k]；相同数字在不同码位不是同一 embedding。这与 32 维 RQ 中心完全不同，两者不绑权重。

历史 ID [B,50] → 查 SID [B,50,4] → 分码位查 embedding [B,50,4,256] → 按“历史时间→商品内层号”展开 [B,200,256]。保留四个 token，不拼成一个商品 token、不把 q_i 直接当推荐器输入。

PAD 商品对应的四个 token 全部屏蔽；可把其输入置零，不能访问真实商品行。历史与 Decoder 的已知商品前缀共用这四张 E。不额外加绝对商品位置表、码位层号向量、BOS 或 EOS。Mixer 中的层身份标记与此处是否额外加标记是两回事。

沿用 [ETEGRec 的独立 embedding 与 T5 组织](https://github.com/BishopLiu/ETEGRec/blob/main/model.py)。本文使用 2 层 Encoder 和 256 宽度，未声称复制其 6 层、128 宽度配置。

### 5.2 一层 Encoder 的计算

| 设置 | 值 |
| --- | --- |
| Encoder 层数 | 2，各层独立参数 |
| d_model／heads／d_kv | 256／4／64 |
| FFN | 256→1024→256；ReLU；不使用 gated FFN |
| 归一化 | T5 RMS 风格，eps=1e-6；有 scale，无 bias，不减均值 |
| dropout | 0.1；按 T5 的输入、注意力权重、子层输出、FFN 内部和末端位置应用 |
| 位置 | 双向相对位置偏置，32 桶，max_distance=128 |
| 初始化 | 从随机参数训练，沿用选定 T5 实现的主体初始化；不加载语言预训练权重 |

对一层输入 X∈R^(B×200×256)，先做 T5Norm，再生成 Q/K/V 并拆成 [B,4,200,64]。注意力分数为：

$$
S^{(h)}_{p,q}=Q^{(h)}_p\cdot K^{(h)}_q
 +b^{(h)}_{\operatorname{bucket}(q-p)}+\operatorname{padmask}_{p,q}.
$$

**标准 T5 不在这里额外除以 √64。**使用 SDPA 实现时必须保持该语义，例如指定 scale=1.0；不能因套通用注意力而改变分数尺度。这个实现细节核对自 [T5Attention](https://github.com/huggingface/transformers/blob/main/src/transformers/models/t5/modeling_t5.py)。

softmax 在 key 维度进行；加权 V、合并四头、输出投影，经过 dropout 后加回 X。随后对子层输入做 T5Norm，经 FFN、dropout，再残差相加。两层结束再执行末端 T5Norm 与 dropout，输出 H[B,200,256]。

Q/K/V/O 和 FFN 线性层沿用 T5 的无 bias 形式。Encoder 自注意力的偏置表 [32,4] 由首层持有，在整个 Encoder 栈复用；Decoder 有自己独立的偏置表，不与 Encoder 共享。不是为每个位置对分别训练参数。

### 5.3 相对位置桶的精确定义

令 d=q−p。Encoder 先分方向：d>0 增加偏移 16，d≤0 偏移 0；n=|d|。每个方向有效桶数 b=16、精细边界 e=8：

$$
f(n;b,e)=
\begin{cases}
n,&n<e,\\
\min\{b-1,\ e+\lfloor (b-e)\log(n/e)/\log(128/e)\rfloor\},&n\ge e.
\end{cases}
$$

Encoder 桶号=方向偏移+f(n;16,8)。d=0 取桶 0。Decoder 为因果：未来位置先屏蔽，对可见位置 n=p−q，使用 f(n;32,16)。桶反映 SID token 的间距；不是商品间距，所以相邻两件商品相同码位相隔 4 个位置。

padding mask 不改变有效 token 的相对距离。Encoder 的有效 query 可双向读取所有有效历史 token；PAD 的输出不进入有效注意力条件。历史原本为空的非法样本须按既有数据协议查明，不能默默补一个新 BOS 改模型。

## 6. 扩散 Decoder：输入、输出与训练视图

### 6.1 条件和输入长度

第 j 件商品的 Decoder 输入：

    前 j−1 件已知商品的 4(j−1) 个 SID embedding
    ＋当前目标的一个带噪连续 query

因此 j=1…5 的有效长度是 1、5、9、13、17。第一件只有 query；不用额外 BOS。训练前缀为真实先前目标，推理前缀为前面真正输出的商品。不给当前／未来目标的 SID，也不把当前干净 z 当作条件输入。

连续 query 的构造：

$$
a_t=\operatorname{MLP}_{32\to128\to32}(\operatorname{SinEmbed}_{32}(t)),
\qquad e_{\rm query}=W_{\rm in}(x_t+a_t)+b_{\rm in}.
$$

时间 MLP 中间 GELU，输入投影 32→256。时间编码只加在连续 query，不广播到所有前缀 token；不额外加列表位置 embedding。

正弦时间编码补全为常用定义：m=0…15，ω_m=exp[−m·log(10000)/15]，拼接 sin(tω_m) 与 cos(tω_m)。使用原始整数 t，不临时改成 t/1000。自定义线性层 Xavier uniform、bias=0；四张 E 用 Normal(0,0.02)。这些是实现初值，不是已证明最优的设计。

### 6.2 四层去噪网络

Decoder 4 层，d_model=256、4 头、d_kv=64、d_ff=1024、ReLU、dropout=0.1、T5Norm eps=1e-6，与 Encoder 相同的子层前归一化和残差规范。四层独立参数；所有 j、t 复用同一套 Decoder。

每层依次进行：

1. 因果自注意力：前缀不能看当前带噪 query；当前 query 可以看所有已知前缀及自身。
2. 历史交叉注意力：Q 来自当前 Decoder 表示，K/V 来自固定 H；屏蔽历史 PAD。
3. FFN：256→1024→256。

每个子层均为 T5Norm→子层→dropout→残差。自注意力有因果相对偏置，交叉注意力不增加相对位置偏置。栈末 T5Norm 后只取当前 query 的输出，经线性层 256→32 得到干净标准化向量预测 x̂_0。没有 SID 分类输出头，也没有语言模型词表输出层。

训练允许把五个 teacher-forcing 视图合并到一个大 batch，提高吞吐；五个视图共享一次历史编码的 H。各视图必须保持原长度、相对位置和因果 mask。如果补到长度 17，query 仍在原来的第 4(j−1) 个零基位置，尾部是屏蔽 PAD，不能把所有 query 强移到位置 16。

### 6.3 参考范围

T5 负责条件序列处理，连续输入／输出投影把 32 维生成空间与 256 维隐藏空间连接。条件连续去噪参考 [DreamRec](https://github.com/YangZhengyi98/DreamRec/blob/main/DreamRec.py)；离散条件与连续带噪表示共同进入 Transformer、时间条件在输入投影前融合，可参考 [Transfusion](https://arxiv.org/html/2408.11039v1#S3)。它们没有验证本模型这套 RQ Mixer＋五商品前缀组合的效果。

## 7. 潜空间标准化、扩散训练与 DDIM

### 7.1 固定标准化

每组选择自己的 RQ 预训练 checkpoint 后，冻结 RQ Encoder。生成固定全目录 z_i 表，以训练目标出现次数 n_i 计算：

$$
\mu=\frac{\sum_i n_i z_i}{\sum_i n_i},\qquad
s=\sqrt{\frac{\sum_i n_i\|z_i-\mu\|_2^2}{32\sum_i n_i}},
\qquad x_i=(z_i-\mu)/s.
$$

μ 是 32 维向量，s 是一个标量。用 FP64 累加统计、保存到版本资产；联合训练期间不更新。非有限值或 s≤1e-8 应判定资产异常，不能悄悄改成逐维标准化。预测逆变换为 ẑ=sx̂+μ；量化、桶内距离、潜空间重建和软对齐都在原始 z 空间进行。

单标量缩放保留相对欧氏几何，不把向量单位化。三组独立预训练，μ、s 与 z 表各自绑定，不跨组混用。

### 7.2 前向加噪与训练目标

噪声总等级 S=1000。cosine 日程 offset=0.008、β_max=0.999：

$$
F(v)=\cos^2\!\left(\frac{v/S+0.008}{1.008}\frac{\pi}{2}\right),\quad
\beta_t=\min\left(1-\frac{F(t)}{F(t-1)},0.999\right),
$$

$$
\alpha_t=1-\beta_t,\qquad \bar\alpha_0=1,\quad
\bar\alpha_t=\prod_{v=1}^{t}\alpha_v.
$$

实际采样使用经过 β 截断后累乘的 ᾱ，不用未经截断的 F(t)/F(0) 替代。

对每条 session 的五个目标位置分别独立均匀抽 t∈{1,…,1000}、ε∼N(0,I_32)：

$$
x_{j,t}=\sqrt{\bar\alpha_t}x_{i_j}
 +\sqrt{1-\bar\alpha_t}\epsilon,\qquad
\hat x_{j,0}=f_\theta(x_{j,t},t,H,c_{i_{<j}}).
$$

一次训练视图只执行一次去噪网络，监督干净向量 x_i。1000 是可抽取的噪声等级，不是每批执行 1000 次；20 是推理调用次数，不是训练等级数。首版不加噪声预测头、v-prediction、SNR 权重、CFG、动态阈值或单位球面裁剪。

### 7.3 推理的 20 个时间点

每个位置从固定评测规则产生 x_1000∼N(0,I_32)。时间点以：

$$
t_k=1+\left\lfloor999\,k/19+0.5\right\rfloor,\quad k=0,\ldots,19
$$

生成后倒序访问，包含 1000 和 1；最后再转到 t=0。对当前 t 和下一个 u<t：

$$
\hat\epsilon_t=\frac{x_t-\sqrt{\bar\alpha_t}\hat x_0}
 {\sqrt{1-\bar\alpha_t}},\qquad
x_u=\sqrt{\bar\alpha_u}\hat x_0+
\sqrt{1-\bar\alpha_u}\hat\epsilon_t.
$$

DDIM η=0，不再注入额外随机噪声；u=0 时 x_0=x̂_0。**是否停止由固定时间表决定，不由“离某件商品足够近”判断。**中间不量化、不把某次最近邻当成下一步输入。20 次结束才逆标准化、落地。五件列表共 100 次 query 去噪调用，但可以批量处理不同 session。

[DDIM](https://arxiv.org/html/2010.02502v4)提供采样方法；[PreferDiff](https://arxiv.org/html/2410.13117v2)提供少步采样的推荐场景参考。20 步是已接受的主设置；此前提到的 50 步验证仍是可另做的诊断，没有变成此次默认追加实验。

## 8. 生成向量如何落地成实际商品

每次落地使用同一版本的有效码本 C、目录 SID 和桶索引：

1. 当前可用目录为全部商品减去本列表已经输出的商品 ID。历史看过的商品仍可推荐。
2. 从残差 r=ẑ 开始。第 ℓ 层只允许选择“延长当前 SID 前缀后，仍有可用商品”的中心编号。
3. 在允许编号里选欧氏平方距离最近的中心，距离平局取较小中心编号，减去该中心进入下一层。
4. 四层结束得到合法 SID 桶，在尚未输出的桶内商品中选 argmin_i ‖ẑ−z_i‖²，完全平局按原始商品 ID 升序。
5. 输出这个实际商品，把它的四位目录 SID 查 E 加到 Decoder 前缀，再生成下一件。

桶内使用量化前 z_i。共享 SID 的商品有相同 q_i，用 q_i 无法消歧。列表内部按商品 ID 去重，不按 SID 去重；同一个多商品桶可先后输出不同商品。

该规则是“逐层合法路径贪心＋桶内最近邻”，**不等于全目录 z 最近邻**。不加入 beam、全目录重排、多个噪声样本挑最好列表或目标标签辅助。目录足够且索引一致时每次合法前缀都有至少一件候选；若出现空候选，应作为索引／版本错误处理，不能自动改另一种落地算法。

推理仅通过 ẑ→硬量化→商品这一链输出商品；训练不对最终 argmin 指望精确梯度。推荐反馈通过第 10、11 节的输入软桥接和对齐损失影响码本。

## 9. 第一阶段：各组 RQ-VAE 预训练

### 9.1 初始化、数据和优化

**有 Mixer 的两组从预训练起就使用 Mixer。**不先统一训练无 Mixer RQ、再在 R5 插入 Mixer；那是早期讨论过、后已替换的另一种对照。

先复制三组共同的 RQ Encoder／Decoder 初始参数和初始化数据顺序。用共同第一批 1024 件商品的编码结果，逐层对残差做 K-means 初始化 256 个中心，每层 100 次迭代，初始化器使用独立固定随机流。四层初始化全部完成以后才正式进入带 Mixer 的前向；初始输出投影为零，故初始化时三组的有效中心一致。B1/B2 的 Mixer 初始参数也直接复制。

| 项目 | 本版设置／来源 |
| --- | --- |
| 预训练数据 | 全部既有目录内容，逐商品均匀采样、每 epoch 洗牌；不按行为流行度加权 |
| 长度 | 10,000 个商品 epoch；不是 10,000 次参数更新 |
| batch／尾批 | 1024 件；保留尾批 488 件，每 epoch 共 11 次更新 |
| 总更新／warmup | 110,000 次；50 个商品 epoch，即 550 次 warmup |
| 优化器 | 一个 AdamW，包含 Encoder、Decoder、基础码本、对应组 Mixer |
| 学习率／weight decay | 1e-3／1e-4 |
| betas／eps／梯度裁剪 | (0.9,0.999)／1e-8／全局范数 1 |
| 日程 | 先线性 warmup，再线性衰减；参考 ETEGRec 预训练调度 |
| 量化 | 硬最近邻；四层 Sinkhorn 均关闭；不用 EMA 更新中心 |
| 评估 | 每完成 50 个商品 epoch，确定性全目录编码并计算碰撞 |
| 选点 | 最低碰撞率 best_collision；严格改善才覆盖，相同保留较早节点 |
| 另外保存 | best_loss、最终状态及预训练曲线；下游仍使用 best_collision |
| 停止 | 正常完成固定预算；不增加“1000 步无改善”之类提前停止规则 |

预训练学习率端点按 ETEGRec 使用的线性 scheduler 约定补全：初始化 scheduler 的累计步数为 0，第 v 次 optimizer 更新使用 η_pre(v−1)，更新后 scheduler 前进一步：

$$
\eta_{\rm pre}(a)=10^{-3}
\begin{cases}
a/550,&0\le a<550,\\
(110000-a)/(110000-550),&550\le a\le110000.
\end{cases}
$$

因此第一次 optimizer 调用的学习率为零，Adam 步数仍正常计数；训练结束后 scheduler 处于零学习率。不得把这里的调度调用顺序直接搬去覆盖第 12 节已单独定义的 R 调度端点。

配方来源：[预训练启动脚本](https://github.com/BishopLiu/ETEGRec/blob/main/RQVAE/run_pretrain.sh)、[默认参数](https://github.com/BishopLiu/ETEGRec/blob/main/RQVAE/main.py)、[Trainer](https://github.com/BishopLiu/ETEGRec/blob/main/RQVAE/trainer.py)。4×256×32、Mixer、共同初始化和裁剪等组合按本设计；不称为完整 ETEGRec 复现。

### 9.2 预训练的损失与梯度：使用 ETEGRec 式 STE

令一个预训练商品 batch 有 n 件。每层先硬选中心 v_ℓ，再构造：

$$
\tilde v_\ell=r_\ell+\operatorname{sg}(v_\ell-r_\ell),\qquad
r_{\ell+1}=r_\ell-\tilde v_\ell,\qquad
q_{\rm ST}=\sum_\ell\tilde v_\ell.
$$

前向仍是硬 RQ 的中心和。RQ Decoder 输入 q_ST，得到 û。损失在替换 STE 前的 v_ℓ 上计算：

$$
L_{\rm pre}=\operatorname{MSE}(\hat u,u)
 +\frac14\sum_{\ell=1}^{4}
\left[\operatorname{MSE}(v_\ell,\operatorname{sg}(r_\ell))
+0.25\,\operatorname{MSE}(\operatorname{sg}(v_\ell),r_\ell)\right].
$$

每个 MSE 对该 batch 的商品数和相应向量维度取平均。原始特征 MSE 的维度为 256，VQ MSE 的维度为 32；不能把四层 VQ 改成求和而仍宣称相同权重。

此处明确沿用 [ETEGRec VectorQuantizer](https://github.com/BishopLiu/ETEGRec/blob/main/RQVAE/models/vq.py)与[残差循环](https://github.com/BishopLiu/ETEGRec/blob/main/RQVAE/models/rq.py)的预训练梯度语义：

- 重建损失通过 STE 更新 RQ Encoder 和 RQ Decoder；没有通过这个 STE 给被硬选的中心直接传重建梯度。
- 基础码本与 Mixer 从 VQ 的中心拟合项收到梯度，因此 Mixer 确实参与预训练。
- 原式层内使用输入直通，残差减法的梯度也由这套 STE 决定；它不同于下面联合阶段的 soft-assignment 代理梯度。

**不得把联合阶段的 Gumbel／cached-hard 公式偷换进预训练，也不得把预训练的输入直通公式拿来替代 T 阶段公式。**

### 9.3 预训练选点后的资产

collision=1−唯一 SID 数／10728。这个定义与“处于多商品桶内的商品比例”不同，两者如同时报告，字段必须区分。best_loss 按完整 epoch 中按商品数加权的平均 L_pre 记录，不能让尾批具有一个整批的权重。

进入联合训练前，为每组选中的 best_collision 保存：

- RQ Encoder、Decoder、基础码本及 Mixer 权重和配置；
- 全目录 z、SID、q、桶索引；
- 训练目标计数 n_i、固定 μ 和 s；
- 第 10 节各层距离尺度 a_ℓ；
- 数据、初始参数、预训练 checkpoint 和上述资产的版本／SHA256 清单。

进入联合阶段时新建 R、T 两个优化器；不把预训练 AdamW 的状态直接挪给不同参数集合。之后交替期间保留这两个优化器状态。这是阶段交接规则的补全，不是每次切换都重置优化器。

## 10. 第二阶段：可微量化与推荐梯度桥接

### 10.1 固定各层距离尺度

选择预训练模型后，用确定性 RQ 得到每件训练目标对应的各层残差 r_iℓ^pre 和有效中心 C^pre。定义：

$$
a_\ell=\max\left\{
\frac{\sum_i n_i\left(\frac1{256}\sum_k
\|r^{\rm pre}_{i,\ell}-C^{\ell,\rm pre}_k\|_2^2\right)}
{\sum_i n_i},\ 10^{-8}\right\}.
$$

统计时按训练目标出现次数加权，对全部 256 个中心的距离取均值，不是只取最近中心距离。使用 FP64 累加、联合训练期间固定。每组独立绑定 a_ℓ。这是对“典型距离”补成唯一公式，属于已授权的实现补全，并非 DIGER 原式或 H1 原式。

### 10.2 当前软分配

T 阶段令 r_i1=z_i，计算 D_iℓk=‖r_iℓ−C^ℓ_k‖²：

$$
p_{i,\ell}=\operatorname{softmax}
\left[\frac{-D_{i,\ell}/(0.1a_\ell)+\sigma(u_T)g_{i,\ell}}{1.0}\right],
$$

$$
\sigma(u_T)=0.2+0.4\left[1+\cos\left(\frac{\pi(u_T-1)}{299}\right)\right],
\qquad u_T=1,\ldots,300.
$$

距离温度 0.1、额外 softmax 温度 1、Gumbel 起止 1.0→0.2 参考原 H1 数值；加各层固定距离尺度属于新 RQ 适配。噪声是在距离温度处理之后加入，不是先在原始距离上加同样幅度再整体除以 0.1。最终规则以上式为准。

g=−log(−log U)，U 为独立 Uniform(0,1)，实现可用 FP32 开区间保护 [1e-6,1−1e-6]。按每次样本中的商品出现位置、RQ 层与中心取噪声；历史重复商品不因为 ID 相同而强制共用随机分配。同一批的五个训练视图复用已经生成的历史／目标表示，不因展开视图又额外抽一次。T 步序不随 microbatch 累积递增。

探索日程只依赖累计 T 步数，不依赖扩散 t，不额外加入 DIGER 的频率门控选择规则。目录刷新、落地、验证和对齐分布都不使用这份 Gumbel 噪声。

### 10.3 两种硬前向／软反向的分工

量化器内部：

$$
a^Q_{i,\ell}=\operatorname{onehot}(\arg\max p_{i,\ell})
 -\operatorname{sg}(p_{i,\ell})+p_{i,\ell},
$$

$$
v_{i,\ell}=a^Q_{i,\ell}C^\ell,\qquad
r_{i,\ell+1}=r_{i,\ell}-v_{i,\ell},\qquad q_i=\sum_\ell v_{i,\ell}.
$$

残差减法不额外 detach；后层梯度可以经过前层的分配和被减去的中心。当前内部硬选择受 Gumbel 影响，不保证等于无噪声目录 SID。

推荐器历史及真实前缀输入：

$$
a^E_{i,\ell}=\operatorname{onehot}(\bar c_{i,\ell})
 -\operatorname{sg}(p_{i,\ell})+p_{i,\ell},\qquad
e_{i,\ell}=a^E_{i,\ell}E_\ell.
$$

c̄ 为当前 10 步 T 开始时的目录 SID 快照。推荐器前向读到的仍是缓存编号对应的 embedding；反向经过当前 p。T 块内这份硬 SID 不变，每次 T optimizer 更新后必须用最新参数重算有效码本和 p。完成十步才统一刷新整个目录，再交给 R 训练。

| 路径 | 硬前向 | 反向 |
| --- | --- | --- |
| 量化器内部、潜空间与 VQ 约束 | 当前带噪分配所选中心 | 当前软分配＋中心直接路径 |
| 输入推荐器的历史、真实前缀 | 本 T 块缓存的确定性 SID | 当前软分配 |
| R 阶段输入 | 当前目录 SID 普通查表 | 只更新 E 和推荐器 |
| 验证／最终落地 | 无噪声硬 RQ／目录约束路径 | 不计算梯度 |

参考 [DIGER gradient-fix 的量化器](https://github.com/junchen-fu/DIGER/blob/gradient-fix/vq.py)、[cached-hard 训练路径](https://github.com/junchen-fu/DIGER/blob/gradient-fix/trainer.py)。小块交替、刷新时机、Mixer 和扩散目标是本模型适配。

### 10.4 梯度真正经过哪里

T 阶段推荐器参数冻结，但计算图保留：

    去噪／对齐误差
      → 扩散 Decoder
      → 历史 Encoder 或已知前缀
      → e=aᴱE
      → 软分配 p
      → 距离 D、残差链
      → 有效码本 C=W＋Δ
      → 基础码本与 Mixer

例如 ∂L/∂p_k=(∂L/∂e)ᵀE_k；softmax 把这个信号传到距离分数；固定残差时，−‖r−C_k‖² 对 C_k 的导数为 2(r−C_k)，再乘相应温度尺度。后层还通过 r_(ℓ+1)=r_ℓ−v_ℓ 回传。

这是代理梯度，不是离散 argmin 的精确导数。不能因为码本有梯度就认定能改善真实推荐。同一输入、同一扩散噪声和固定硬 SID 下，单独去噪损失的前向数值可能不随 T 更新立即变动；应在目录刷新后看推荐指标。

T 时推荐器设 eval 关闭 dropout，但不得用 no_grad 包住整个推荐器；冻结参数与禁止输入梯度不同。R 时对常量码本的对齐计算仍要保留预测 ẑ 的梯度，也不能把整项 KL 放进 no_grad。

## 11. 联合阶段的四项损失

以下 N=5B，商品重复出现保留重复权重；不是先对 batch 内商品去重。历史商品通过推荐输入链影响 T，潜空间重建与逐层 VQ 只对本批五位置目标计算。PAD 不进入任何统计。

### 11.1 去噪损失：标准化空间的目标预测

$$
L_{\rm denoise}=\frac1{32N}\sum_{n=1}^{N}\|\hat x_{n,0}-x_n\|_2^2.
$$

五个列表位置等权，所有噪声等级按均匀抽样权重；x_n 是固定目标，没有目标侧梯度。这一损失在 R 更新推荐器，在 T 通过第 10 节输入桥接更新码本与 Mixer。

### 11.2 软量化对齐：单向 KL

对于真实目标 n，第 ℓ 层先取同一个缓存真实 SID 前缀对应的有效中心和：

$$
b_{n,\ell}=\sum_{m<\ell}C^m_{\bar c_{n,m}}.
$$

两侧都使用 b_nℓ，不各自进行一次不同的自由选码：

$$
P_{n,\ell,k}=\operatorname{softmax}_k
\left(-\frac{\|(z_n-b_{n,\ell})-C^\ell_k\|^2}{0.1a_\ell}\right),
$$

$$
Q_{n,\ell,k}=\operatorname{softmax}_k
\left(-\frac{\|(\hat z_n-b_{n,\ell})-C^\ell_k\|^2}{0.1a_\ell}\right).
$$

$$
L_{\rm align}=\frac1{4N}\sum_{n,\ell}\sum_{k=0}^{255}
\operatorname{sg}(P_{n,\ell,k})
\left[\operatorname{sg}(\log P_{n,\ell,k})-\log Q_{n,\ell,k}\right].
$$

KL 对 256 个中心求和，对目标和四层取平均，不能额外除以 256。用 log_softmax 计算，不直接对可能下溢的概率取 log。不加 Gumbel，不加合法目录候选 mask。

停止的是整个真实 P 分支；P 每次根据当前码本重新计算，不是永久冻结的一张教师概率表。预测 Q 分支的当前有效中心及前缀中心和 b 都保留 T 梯度，预测 ẑ 也保留通过推荐输入路径的梯度。R 阶段 C 固定，KL 仍可更新预测 ẑ 和推荐器。

参考 [ETEGRec SIA](https://arxiv.org/html/2409.05546v3#S3.SS3.SSS1)的软分布对齐思想，权重数量级参考其报告。本设计使用“预测商品表示→真实商品表示”的单向 KL 并停止目标支路；**不是 ETEGRec 的对称 KL 原式，也未证明在本任务更稳定。**

### 11.3 潜空间重建：四层之和接近固定 z

$$
L_{\rm latent}=\frac1{32N}\sum_n\|q_n-\operatorname{sg}(z_n)\|_2^2.
$$

q_n 使用当前带软梯度的 RQ 内部选择，z_n 固定。比较在原始 32 维潜空间，不把 q 输入 RQ Decoder 重建 u；不改成比较标准化 x，避免隐含改变损失权重。

### 11.4 逐层 VQ：各层拟合当时残差

$$
L_{\rm VQ}=\frac14\sum_{\ell=1}^{4}
\left[
\operatorname{MSE}(v_\ell,\operatorname{sg}(r_\ell))
+0.25\,\operatorname{MSE}(\operatorname{sg}(v_\ell),r_\ell)
\right].
$$

MSE 对 N 个目标及 32 个维度平均，v、r 来自第 10 节的联合量化路径。第一项使当前中心拟合残差；第二项调整能收到梯度的残差来源。RQ Encoder 已冻结，第一层残差 z 是常量，因此第一层承诺项不更新 Encoder；后层残差仍可把梯度传到前层码本／Mixer。不能照搬“承诺项始终更新 Encoder”的预训练解释。

L_latent 与 L_VQ 确实重叠：前者约束四层总和，后者规定逐层目标与 stop-gradient 方向。两者不是两份完全独立监督，但也不能因为最后残差有关联，就静默删除其中一项。

### 11.5 总损失和参数去向

$$
\boxed{L_R=L_{\rm denoise}+0.0003\,L_{\rm align}}
$$

$$
\boxed{L_T=L_{\rm denoise}+0.0003\,L_{\rm align}
 +1.0\,L_{\rm latent}+1.0\,L_{\rm VQ}}
$$

| 损失 | 原始系数 | R 阶段 | T 阶段 |
| --- | ---: | --- | --- |
| 去噪 | 1 | 推荐器全部相关参数 | 输入桥接→码本／Mixer |
| 对齐 | 0.0003 | 预测向量→推荐器 | 预测侧量化与输入桥接→码本／Mixer |
| 潜空间重建 | 1 | 不纳入 R 总损失 | 码本／Mixer |
| 逐层 VQ | 外部 1，内部 β=0.25 | 不纳入 R 总损失 | 码本／Mixer及前层残差链 |

推荐器预热也使用完整 L_R，对齐从预热起启用。0.0003 是参考值，不代表与 ETEGRec 原式等效。首轮三组固定使用；此前讨论的 λ 搜索／λ=0 消融是后续选择，不默认扩充此次三组预算。

| 参数 | R 优化器 | T 优化器 |

每轮 709443=692×1024+835，所以 R 有 693 次更新。R35 共 U_R=24255。第 u_R 次更新使用：

$$
\eta_R(u_R)=
\begin{cases}
3\cdot10^{-4}\,u_R/500,&1\le u_R\le500,\\
3\cdot10^{-4}\,[1+\cos(\pi(u_R-500)/(24255-500))]/2,&500<u_R\le24255.
\end{cases}
$$

最后一次调用的 lr=0，仍计入既定 R optimizer step。这是上一版已写出的端点约定；实现时显式按此计算，避免 scheduler 的调用顺序引入错一位。5R 预热与前 500 个更新的 lr warmup 不是同一件事。

每个有效 batch 内按实际 session 数累积梯度，最后才裁剪、step、zero_grad。尾批 835 条的分母为 835，不是 1024。对一个含 m 条的 microbatch，若其损失已经取均值，应乘 m／本有效 batch 总数后 backward。不能每个 microbatch 都 step，也不能对 microbatch 平均值再无权平均。

## 13. 一次训练与一次生成的完整步骤

### 13.1 R 更新

1. 从本 R epoch 的顺序取一个有效 batch；当前 C、目录 SID 和索引已经冻结。
2. 查历史与目标 SID；以 E 构造历史 token，Encoder 一次得到 H。
3. 为五个目标各自抽 t 和高斯 ε，构造只包含先前真实商品的五个 Decoder 视图。
4. Decoder 一次去噪得到 x̂_0，逆标准化得到 ẑ。
5. 计算去噪和对齐，按实际样本数累积，更新推荐器。
6. C、Mixer、z 表、SID 全部保持不变。下一个 R batch 重新计算 H，不能跨参数更新缓存旧 H。

### 13.2 T 更新

1. 推荐器冻结并 eval；保留当前十步块的缓存 SID c̄。
2. 取 T 持续迭代器下一个有效 batch，用最新 W、Mixer 计算有效 C。
3. 对历史和目标商品计算第 10 节软分配；构造 cached-hard 的输入 embedding，以及当前内部量化 q、r、v。
4. 与 R 相同地构造五个带噪训练视图，经冻结推荐器计算四项损失。
5. 累积后只更新 W 和 Mixer；下一次 T 前向重算 C，不能拿上一步 detach 的 C 冒充当前可微码本。
6. 共完成十步，确定性重编码全部目录，原子替换 SID、q、桶和合法前缀版本，进入下一 R epoch。

T 的单次有效更新中参数不变，可对各 microbatch 分别重建码本计算图以释放内存；不得跨 optimizer step 复用旧图或旧有效中心。

### 13.3 推理一份五件列表

1. 锁定 checkpoint 和同版本 Tokenizer、z／统计量／目录索引。
2. 历史普通查 E，Encoder 计算一次 H；模型 eval、无反向梯度。
3. 第 j 件初始化固定高斯 x_1000，使用当前真实落地前缀与 H 执行 20 次 DDIM。
4. 逆标准化，对可用目录执行第 8 节落地，记录商品 ID。
5. 把该实际商品的 SID 加入前缀；不得把最后一个 noisy query 当作持久前缀。
6. 循环五件，输出 [B,5] 实际商品 ID，再按相同商品协议计算指标。

## 14. 验证、选模、指标和必须保留的结果

### 14.1 选点与测试规则

按用户2026-11-11正式Goal修改为第12节R5至R35的31处完整验证节点；每个节点先保存模型状态，再评完整 71,657 条验证样本。按真实商品级、单份五件列表的平均 NDCG@5 选 best，严格高于才更新；完全相同取较早节点。

主推理固定每件 20 步 DDIM、η=0、每样本一份五件列表，不能为某组多采样再择优。训练结束只测验证 best 与最终 R35 的完整测试集；如果两者是同一 checkpoint，复用一次测试结果，保留双重身份。测试集不选 checkpoint、不选 λ 或学习率。

### 14.2 指标口径

对一个样本的真实五件目标集合 G 和有序预测 (î_1,…,î_5)，a_j 表示 î_j 是否为目录内、首次出现且属于 G 的商品：

$$
\operatorname{NDCG@5}
=\frac{\sum_{j=1}^{5}a_j/\log_2(j+1)}
{\sum_{j=1}^{5}1/\log_2(j+1)},\qquad
\operatorname{Recall@5}=\frac{\sum_j a_j}{5},\quad
\operatorname{HR@5}=\mathbf1[\sum_j a_j>0].
$$

最后对所有样本等权平均。正确 SID 但错误商品不算命中；不要求第 j 个预测必须等于第 j 个真实目标。出现非法／重复／缺失输出时原位置计 miss，不删位置、不缩小分母，同时报告异常率。参考本地 [商品级指标](../../../scripts/listwise_diffgrm/metrics.py)。

至少报告 NDCG@5、Recall@5、HR@5、完整五件输出率，以及对应样本量。记录逐样本输出和指标，以便之后做同样本比较；不只保留四舍五入的总体均值。

### 14.3 固定推理噪声与随机流

已定评测 seed=20241111。初始噪声只依赖：

    noise_protocol_version、evaluation_seed、split、sample_id、j

不得包括组名、checkpoint、轮次、batch 大小或进程号。补全方案：按固定 UTF-8 字符串顺序连接上述字段，用 SHA256 的前 8 字节按 little-endian 产生种子，用固定版本 NumPy 的 PCG64 生成 32 个标准高斯数，再存成 FP32。提前生成共享噪声表及 SHA256；三组及所有节点读取同一份。字符串格式与 NumPy 版本写入运行 manifest，后续恢复复用原表，不在另一环境重新生成后假定逐位一致。

训练随机流分别管理：共同参数初始化、Mixer 初始化、预训练数据顺序、R 数据顺序、T 数据顺序、扩散 t／ε、Gumbel、dropout。对应流的种子不带组别名；初始可共享参数直接复制，不能仅说 seed 相同就假定参数相同。验证使用独立随机流，不消耗训练状态。

| 时点 | 必须记录的内容 |
| --- | --- |
| 每个 R epoch | L_denoise、原始及加权 L_align、总损失、lr、实际样本／更新数、耗时 |

| 每次全目录刷新 | SID 改变比例、各码位改变比例、利用率、困惑度、两类碰撞指标、各层 RMS 和 Δ/W |
| RQ 预训练 | 内容重建、VQ、总损失、目录碰撞、利用率、z 方差／范数、lr 与选择节点 |

统一定义如下：

- SID 改变比例：本次和上次目录刷新相比，四位中至少一位改变的商品数／10728。
- 第 ℓ 层利用率：被至少一件目录商品选中的中心数／256。
- 第 ℓ 层困惑度：exp(−Σ_k p_k log p_k)，p_k 按目录商品均匀计数；不用 session 流行度替换。
- 碰撞冗余率：1−唯一完整 SID 数／10728；碰撞商品比例：属于桶大小>1 的商品数／10728，另列字段。
- 有效中心变化：‖C_new^ℓ−C_old^ℓ‖_F／max(‖C_old^ℓ‖_F,1e-8)；不是重新排列中心后再比较。
- 自由 RQ 合法率：对同一个生成 ẑ，取消合法候选约束做普通四层 RQ，所得 SID 是否存在于完整目录。另记该桶是否还有未选商品。
- 约束改码率：目录约束路径与同一 ẑ 的自由路径是否不同；统计完整 SID 和逐码位两个口径。

loss 曲线按 R epoch／T optimizer step 标明各自横轴，不把预训练商品 epoch 或扩散时间 t 混进同一“轮次”。预训练选点指标、训练 loss 和推荐指标分别解释。原始 loss 下降不能直接推出推荐更好，合法率低也不能独自证明生成器是唯一瓶颈。

### 14.5 恢复资产

每个正式验证节点保存不可被后续滚动覆盖的完整 checkpoint。至少包含模型全部相关状态、R/T 优化器及计数、调度配置、R/T 数据排列和游标、全部随机流、预训练绑定、z／μ／s／a_ℓ 版本、当前 C 和目录索引版本、best 记录、数据及代码／环境清单。

RQ Decoder 虽不参与联合训练，所选预训练 checkpoint 仍保留，不能为了省空间删掉唯一恢复来源。可将大 z 表与索引作为带哈希的不可变依赖，不必复制进每个 checkpoint，但必须保证引用能恢复。

## 15. H100 执行设计：保留数学规则，再提高吞吐

本节承接上一轮性能讨论。沿用单卡实现起点，每组训练一个独立模型，不加入 DDP。各组是否同时申请资源是后续运行安排。以下方案没有新模型测速结果，不能据此承诺训练小时数或 GPU 利用率。

### 15.1 可以按既定语义组织的实现

| 位置 | 执行方式 | 必须保留的条件 |
| --- | --- | --- |
| 数据 | 商品特征、z、SID 和紧凑样本数组尽量常驻 GPU；否则预取、固定内存、非阻塞传输 | 内存不足可回退分批，数据和顺序不变 |
| R 前向 | 冻结 C／SID 缓存；一个 batch 的 H 算一次；五个训练视图批量处理 | 不跨推荐器参数更新缓存 H；保持 teacher-forcing 边界 |
| T 前向 | 最新参数重算 C 和可微分配；cache 仅保存本块硬 SID | 不能 detach 掉推荐梯度，不能复用上一步 C |
| 层内 Mixer | 把四层作为四个 256-token 注意力问题批量计算 | 共享参数与相同层标记；等价于块对角 mask |
| 因果 Mixer | 按 RQ 层块实现可见范围 | 不能改成中心编号逐 token causal |
| 推理历史 | H 和每个 Decoder 层的历史 cross-attention K/V，在五件列表中复用 | 同 checkpoint、同样本、eval 状态 |
| 推理前缀 | 缓存已知 SID 前缀的逐层 K/V，在当前商品的 20 个去噪步中复用；下一件追加四个实际 SID token | 前缀看不到 query，且未加时间条件；删除旧 noisy query，不缓存它作为新前缀 |
| 落地／指标 | 合法码候选、桶内距离、去重和指标尽量张量化 | 保持第 8、14 节精确规则与平局顺序 |
| 日志 | GPU 端累计后定期批量回传；减少热路径 item、cpu、tolist 和逐样本写盘 | 仍完整记录指标及必要错误，不删科学诊断 |

层内组有效注意力位置对为 4×256²，密集 1024-token 全注意力为 16×256²；因果组可见块有 10 个。**仅加 mask 不保证底层跳过被屏蔽的计算**，必须以实际实现和 profile 为准。

### 15.2 数值规则和未锁定的执行参数

| 项目 | 状态与规则 |
| --- | --- |
| 有效 batch | 已定为 1024；不能为跑满卡擅自增大 |
| microbatch／累积 | 待测速；上一版的 32×32 只是保守默认，不是正式最优值；可比较 128、256 等候选 |
| 各组一致性 | 为相同阶段选三组都可承受的共同 microbatch／累积配置；T 与 R 可分别选，正式开始前锁定 |
| 推荐器精度 | 沿用上一版 BF16 计算、FP32 主权重／优化器；推理也以共同 BF16 配置为本版实现默认，数值验收对照 FP32 |
| 敏感计算 | 码本、Mixer 尺度与量化距离、softmax／KL、loss 归约、DDIM 状态更新使用 FP32；固定统计量 FP64 累加 |
| SDPA／融合 kernel | 实现候选；保持 T5 的 scale=1、相对偏置和 mask；实际用哪种 kernel 待测 |
| fused AdamW | 可用候选，必须三组同配置、完整保存状态；不能改 lr／eps／权重衰减语义 |
| torch.compile | 后置候选；仅在 profile 显示收益、数值核对通过后考虑，不作为第一版必须步骤 |
| 不自动采用 | FP8、放宽 TF32 精度、减少 DDIM 步数、删对齐、改 batch 或省略正式验证 |

由于 BF16 和不同 kernel 可能改变边界附近的选码，量化与最终距离保持 FP32；实现时用同一小批核对预测、损失和梯度，必要时回退相关计算。microbatch 变化也可能改变 dropout 抽样顺序，不能宣称与另一划分逐位相同；公平性靠三组锁定同一规则和复现状态保证。

只安排一次合并的短验收，同时检查正确性和有效 batch 吞吐。观察完整有效更新的耗时、数据等待、前反向、量化、目录刷新和生成验证；不只看单个小 kernel，也不只用 nvidia-smi 利用率判断训练效率。运行前不为每项各开一轮冗长实验。

## 16. 首轮对照与可以回答的问题

| 组别 | 预训练 | 联合阶段 | 主变量 |
| --- | --- | --- | --- |
| B0 | 无 Mixer 的 RQ-VAE | 基础码本参与 T，推荐器参与 R | 不做中心交互 |
| B1 | 加层内四头 Mixer | 相同层内结构继续 T 更新 | 每层中心内部交互 |
| B2 | 加层间因果四头 Mixer | 相同因果结构继续 T 更新 | 后层直接读取自身与前层中心 |

首轮 seed=2024。各组训练到 R35/T300，预训练 10000 个商品 epoch，评测协议相同。B1/B2 参数量一致、初始权重一致；B0 缺少 Mixer 参数是这个消融的本来差别，不能声称三组总参数完全一致。

三组**各自预训练**意味着下游 z 空间与 SID 可能不同。因此主比较回答“整个带该交互的方案是否改善”，不能单独归因为“仅联合阶段多了某个注意力层”。同 epoch／更新数也不等于同 FLOPs，时间和显存需同时报告。

最终表至少并排列出：best 的 R/T、验证 NDCG/Recall/HR、该 best 的测试；R35 的验证和测试；关键编码状态。旧 H0、H1、H1 Freeze 可作为外部性能参照，但其 PSE、离散生成与 beam 推理不同，不能称为同预算的纯 Mixer 消融。

首轮单 seed 只提供初步证据。2025、2026 复验、共同预训练起点的交互消融、λ 搜索、50 步推理、冻结或更换落地方式均属于后续候选，不在未授权时自动增加。

## 17. 实现时的最小验收与版本管理

本次先写清验收目标，**尚未执行模型测试**。实现完成后合并检查以下关键链条，避免重复测试同一件事：

1. 张量形状、独立 E 和两种 Mixer 掩码正确；改变未来目标不会改变较早预测的条件。
2. T 只改码本／Mixer，R 只改推荐器，RQ Encoder 始终冻结；单独 L_denoise 的梯度确实通过输入桥接到达码本。零初始化时内部 Mixer 梯度的阶段性例外按第 4 节解释。
3. 预训练 STE 与联合 soft-assignment 梯度分开验证；损失归约、KL 方向及 sg 位置符合第 9～11 节。
4. T 块后原子刷新索引；量化、碰撞桶、目录落地同版本；自由与约束 RQ 的差异记录正确。
5. 固定噪声下不同评测 batch 给出数值容差内一致输出；前缀／历史缓存与不缓存的参考前向一致。
6. 同一小段有效 batch 验证吞吐；一次 checkpoint 保存恢复核对下一步状态和计数，复用这次检查，不为每个分组重做无关验收。

新模型使用独立命名空间和配置版本，不直接覆盖已完成旧实验的源码快照、配置或 checkpoint。实现入口、具体模块路径、依赖版本、短测选出的 microbatch/kernel、远端运行路径，在实施时写入 run manifest；它们不是本次已经存在的新实现。

对于数值非有限、断连或作业失败，保存错误与最新完整状态，按既有实验管理规则处理；不通过重置模型、改 seed、改超参数来冒充原实验续跑。常规恢复不改变本设计。
