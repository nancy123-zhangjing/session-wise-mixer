# 新模型设计与既有约定的一致性审查

审查日期：2026-11-11。对象：[完整设计](RQCD_MIXER_FULL_DESIGN_20261111.md)。本次审查是文档和公式审查，不是新模型实现、训练或性能验收。

**结论：核心架构、损失、训练预算和评测方案与最后接受的方案一致。**容易混用的早期候选已排除。对于先前未逐项确定的实现细节，文档明确标为“补全”；microbatch、kernel、软件版本与实际耗时仍未实测，没有冒称确定。没有改动模型代码、没有启动新实验，也没有修改给学长阅读的简版飞书。

## 4. 明列的实现补全，不冒称用户逐项指定

以下并非新的研究分支，目的是消除相同文字被实现成不同模型的歧义：

| 补全点 | 明确方式／性质 |
| --- | --- |
| 各层典型距离 | 按训练目标频次，对所有256个中心距离取均值；选定预训练后固定。沿用上一版明确公式。 |
| LayerNorm／线性bias与初始化 | Mixer逐中心LN再加层标记；QKV带bias、输出投影零；T5按其自身规范。 |
| T5 attention scale | 标准T5 QK不额外除√d_k；通用SDPA须scale=1。这是标准T5实现语义澄清，避免早期通用Transformer解释造成混用。 |
| T5偏置共享 | Encoder／Decoder各有首层持有的32×4表，在各自栈中复用；交叉注意力不另加相对偏置。 |
| 预训练STE | 用ETEGRec式输入直通、对应VQ损失；与联合阶段的soft-ST分开。说明预训练Mixer由VQ项获得梯度。 |
| 端点与时钟 | 预训练scheduler的step0、R第u步公式、T噪声起止、DDIM20点及t=0结束均写明。 |
| 随机流 | Gumbel按商品出现位置抽样，五视图复用；评测SHA256→PCG64、固定噪声表，不随batch分块变化。 |
| 数值范围 | 推荐器BF16默认细化到推理；敏感距离/概率/损失/DDIM保留FP32、统计FP64，短验收对照FP32。属于本稿补全，非用户逐项指定精度。 |
| 精确落地规则 | 中心距离平局取小编号；桶内平局取小原始商品ID；索引异常不能偷偷换全目录ANN。 |
| 阶段优化器 | 预训练完成新建联合R/T优化器；交替期间不重置。 |
| 日志／恢复 | 统计分母、每个验证节点不可覆盖checkpoint、版本绑定、大结果远端保存。 |

仅执行细节尚待填写：microbatch／累积、实际kernel、是否compile、软件版本、远端运行目录与耗时。它们不会在本文中假装已有实测结论。如果未来不得不改变核心规则，需要另记版本和差异。

## 5. 数学与文档检查范围

本次用标准库进行日程算术、DDIM时间点、损失系数文本、关键约定及本地链接检查，结果写入 [文档核对收据](full_spec_20261111/design_review_receipt.json)。不导入训练框架、不加载checkpoint、不跑训练或推理。

人工审查重点包括：

- 五件训练前缀没有当前／未来目标泄漏；批量展开不改变相对位置。
- 四张SID embedding、四个RQ层、32维潜空间和256维推荐空间保持分离。
- 停止真实KL分支梯度与保留预测分支梯度同时成立。
- T冻结推荐器参数但保留输入梯度；R冻结码本但保留预测z的梯度。
- 所有更新次数、尾批权重与验证节点按新日程计算。
- 层内／因果掩码区别发生在RQ层块，不发生在中心编号顺序。
- 原文档与已有实验结果未被覆盖；新模型有效性和性能仍待实际实验。

审查没有给出“模型已经跑通”的结论，也没有用历史RQCD脚本的测试代替本模型测试。完整稿及这份审查构成实施前依据。
