## 2. 研究主线及已经改变的认识

总问题：**Tokenizer 能否通过推荐反馈学到适合列表推荐的编码，码本之间的信息交互能否进一步提升效果？** 用户希望有可靠基线，再研究 Mixer 的作用，不是只把一个模型跑通，也不是预设所有交互都有效。

研究链条是：Tokenizer 与推荐器适配 → 联合训练/可微量化 → session-wise 五件列表 → 码本交互 → 效果、稳定性和可重复性验证。

| 已有实验 | 回答了什么 | 仍未回答什么 |
|---|---|---|
| 旧 PSE＋DiffGRM 的 H0/H1 | H1 持续改编码后期可能严重退化；适时冻结能保留收益 | 退化的充分原因、最合理的冻结策略 |
| 降频、门控、提前干预、冻结 | 降低 T 总量或更新幅度并不自动变好；部分小幅更新有短期收益 | 收益是否跨 seed、阶段和编码方式稳定 |
| 三 seed 的 H0 Freeze/H1 Freeze | 同冻结日程下 H1 在三个 seed 的 best、R35 测试均较高 | Mixer 内部机制与更广泛泛化 |
| Grid、去编号标记、Decoder 前缀 | 简化或改组织结构不一定提高效果；保留了负结果 | 是否适合新 RQ/AR 结构，不能直接迁移结论 |
| 内容潜向量连续扩散＋RQ | 原始 B0/B1/B2 整体低分，不能直接作为可靠竞争基线 | 目标、监督、生成器、量化落地各自的责任 |
| CF/Hybrid 目标及 RQ 落地监督 | CF 版本有明显改善；Hybrid 未显示相同收益 | 同时改了目标和监督等，不能单独归因 |
| CF 无/有 Mixer、R9 冻结 | 冻结改善末端保留，没产生新的验证 best；旧协议测试上存在 Mixer 线索 | 单 seed、验证/测试分布不同，不能普遍化 |
| TIGER/DIGER session-wise | 给新范式提供 AR 竞争参照；TIGER 预训练稳定性必须先解决 | 各方法预算不同，不是纯 AR/扩散因果消融 |
| 最新 L5O 首波六组 | 同协议下 CF 仍明显低于 H0/TIGER；H1 仍有坍缩反例 | TIGER 有 Mixer 最终测试、后续机制与重复性 |

## 3. 先区分模型与评测协议

### 模型名字

| 路线 | Tokenizer/推荐器 | 列表前缀 | Mixer 与训练 |
|---|---|---|---|
| 原 H0/H1 | PSE，4 个 256×64 子码本；DiffGRM 式商品内离散生成 | 已生成商品经 SID embedding/商品聚合后并入历史，重新编码 | H0 无、H1 有 Cross-PSE Mixer；两者都联合训练 |
| 新 RQCD B0/B1/B2、CF | RQ-VAE 32 维潜空间；条件连续扩散产生向量，再 RQ 落地 | 固定真实历史 Encoder 输出，生成商品 SID 放 Decoder 前缀 | B0 无；B1 层内；B2 按 RQ 层级 causal；CF 初始版本有层内 Mixer |
| TIGER 式 T0/T1、修订 T0A/T1A | 3 个 RQ 语义码位＋1 个消歧码位；SID 自回归 | 每生成一件，将 SID 前缀并入历史重新编码 | Mixer 若有，在 RQ 预训练中训练；推荐阶段整个 Tokenizer 固定 |
| DIGER 式 AR-D0/D1 | 作者 gradient-fix 版本的可微量化＋AR，适配五件列表 | 同 AR session-wise 改造 | 每 batch 联合更新，保留方法核心节奏；D1 加层内 Mixer |

H0 不等于“固定 Tokenizer”；TIGER 有 Mixer 不等于“推荐损失训练 Mixer”。TIGER 与 DIGER 不能简化成配置完全相同、仅多一个梯度开关。原 H1 的跨 PSE 全注意力也不是新 RQ 的层内 Mixer。

### 两套评测必须分开

**旧全局时间协议：**KuaiRec，目录 10,728 件，训练 709,443 条五件样本、验证 71,657、测试 53,194；历史通常最多 50 件。由交互构造的五件目标列表，不等于真实曝光推荐列表。主指标为商品级 NDCG@5，best 由完整验证选择。8192 固定诊断子集分数不能替代全量验证/测试。验证后段低于测试不矛盾：目标构成、用户与历史等不同，时间靠后不保证更难。

**最新 L5O：**每位用户最后 5 条交互做测试，前 5 条做验证，更早交互做训练；历史上限 128，推理过滤历史商品。主指标 EV-NDCG@5 使用 watch_ratio≥1.0，≥2.0 作敏感性分析；同时报告 Imp Hit@5 等。测试 7,176 人，主 EV 有效人群 5,645。不能把旧 NDCG 与新 EV-NDCG 的绝对分数直接作提升比较。旧 HANDOFF 的“最后 session”以这里和 WAVE_REPORT 的五条交互定义为准。

## 4. 旧 H0/H1：为什么后来研究稳定性和结构

R 表示推荐器完整 epoch，T 表示 Tokenizer **一次优化器更新**，不是一个 epoch。旧共同起点 R5/T0；随后每块先 40 次 T 更新，再 3 个 R epoch，共到 R35/T400。每个 R 有 693 次更新，全局 batch=1024。

| 旧协议，seed2024 | 验证选 best | best 验证 | best 测试 | R35 测试 |
|---|---:|---:|---:|---:|
| H0 持续交替 | R32 | 0.008920 | 0.008607 | 0.008483 |
| 原 H1 持续交替 | R20 | 0.009372 | 0.007944 | 见原完整节点补测材料 |
| H1 在 R20 冻结 Tokenizer | R32 | 0.010690 | 0.009431 | 0.008956 |
| D：每块 20T 后 3R，总 T200 | R23 | 0.008791 | 0.008074 | 0.005528 |
| E：每块 40T 后 6R，总 T200 | R29 | 0.009198 | 0.008621 | 0.004845 |

Freeze 冻结基础码本、Mixer、SID；推荐器及其 SID embedding 继续学习。不能说冻结把 Mixer 删了。D/E 总量相同但更新时间、块大小和编码刷新时机不同；“推荐器有更多适应时间”不保证指标更高。

后续控制还做过：R20 固定 Mixer 修正门控 0.1；新增修正系数 0.1→0.01；R14 提前门控、R17 恢复系数 1；从所得新 R20 冻结或线性收紧；同一线性组 R26 后固定 0.06427136、固定 0.01 或完全冻结。必须区分门控和降学习率：门控控制**有效 Mixer 输出的新增修正**，非冻结分支基础码本仍更新；路径依赖门控状态是 checkpoint 的一部分。

同一原线性 R26 父模型的后续策略，best 测试 / R35 测试：固定 0.06427136 为 0.008902 / 0.006971；固定 0.01 为 0.009136 / 0.008472；完全冻结为 0.008902 / 0.008332；原线性继续为 0.008902 / 0.008353。小幅继续更新有线索，但单 seed、小差异，不能得出越小越好。不同父模型不能当单一系数消融。

进一步结果：

- **三 seed 固定 R20 冻结对照**：H0 Freeze 的 R35 测试均值±样本标准差 0.006719±0.001638，H1 Freeze 为 0.008135±0.000938（均值 +21.08%）。验证选 best 测试均值 0.007491 vs 0.008371（+11.75%）。三个 seed 均同方向，支持继续研究；不宣称三 seed 已证明普遍显著，2024 为历史探索环境。
- **Grid**：原 H1 Freeze / 层内 Grid / 再加同码位跨商品 Grid，best 测试分别 0.009431 / 0.008793 / 0.008249，R35 为 0.008956 / 0.006577 / 0.006825，未超过原方案。
- **去中心编号标记**：保留码本身份，从原 R5 到 R20。best 在 R14，验证 0.008337、测试 0.008104；原 H1 best 验证更高、测试 0.007944。不能仅凭测试略升宣称简化稳定有效。
- **固定历史＋Decoder 前缀 A/B**：A 为非对称 self-attention，B 为独立 cross-attention；B 优于 A，但四个新 H0/H1 变体均未超过同 R20 范围内原模型。H0-B best 测试 0.007382 < 原 H0 0.008923；H1-B 0.005828 < 原 H1 0.007944。这是旧离散模型的证据，不能据此否定所有 RQ/AR 前缀设计。
- 已有同一 SID 保持不变的 R 训练段仍掉分。不能把所有退化都归为 T 改码，也不能直接认定为 MEDA 的 one-epoch overfitting。原静态训练集不因轮数增加变成新的时间数据；“冻结错过后期新分布”不是已证实解释。

## 5. 新范式：保留连续生成，为什么这样设计

学长提出先生成商品连续向量，再用 RQ-VAE 量化回 SID/商品；仍做五件列表，之后研究交互。用户明确希望建立可信 baseline，再看码本交互，而不是为简便随意删掉 SID embedding 或改已有方法。

确定的主体流程：

1. 商品输入特征 → RQ Encoder → 32 维连续潜向量 z；4 层残差量化 → SID 与量化和 q。z 是生成目标，q 不等于 z。
2. 历史 ID 查目录 SID，每件 4 个码位分别查独立 SID embedding（256 维），50 件展开为 200 tokens，经 2 层 T5 Encoder。不是直接把 q 当历史 embedding，也不是把四码位先压成一枚商品 token。
3. 每件商品从 32 维噪声开始，经输入投影、时间/列表位置条件、4 层去噪 Decoder 和输出投影预测干净 z。历史 Encoder 输出复用；先前生成商品的 SID 作为 Decoder 前缀。
4. 训练随机采一个噪声等级做一次去噪预测；推理默认 20 步 DDIM，噪声日程 1000 级。训练不等于每个样本串行去噪 20 次。
5. 生成向量还原尺度后，逐层按合法目录前缀做 RQ 落地；同 SID 碰撞桶内按商品潜向量距离消歧，遵守去重等协议；选中的真实目录商品 SID 成为下一件前缀。
6. 预训练训练 RQ Encoder/Decoder/码本；联合阶段冻结 RQ Encoder，z 固定，RQ Decoder 不参与推荐训练，使用潜空间重建/VQ约束。R 阶段只训练推荐器；T 阶段冻结推荐器参数但保留其对输入的梯度，更新码本/Mixer。不能用整个 no_grad 切断 T 的推荐反馈。

Mixer 两种：层内 4 头 attention；或按 RQ 层级做 block-causal attention，让后层看前层，前层不看后层。不是对同层中心编号强加先后顺序。只用层身份、不用中心编号标记；输出投影零初始化。按各层码本 RMS/参考层 RMS 缩放修正是尺度设计，**不保证修正占基础码本的比例完全一致，也不等于固定 0.1 门控**。

新范式联合日程：5R warmup，随后 30 次“10 个 T 优化器更新＋1R”，总 R35/T300。和原 H1 的 40T＋3R 不同。

来源：`docs/research/rqcd_mixer/RQCD_MIXER_FULL_DESIGN_20261111.md`、一致性审查、`RQCD_TARGETS_DESIGN_20261113.md`。ETEGRec 提供 SID/RQ/协同表示参考，DIGER gradient-fix 提供可微量化及联合训练参考，LETTER 提供内容/协同对齐启发，SASRec 风格教师提供协同表。**完整组合是本项目设计，不能说某篇论文已经原样验证过。** 讨论具体论文公式时重新核查固定原文/代码，不凭旧聊天背书。

已经做过的诊断，不要再次当成待做：

- 真商品 z 回量化 SID 正确率 100%，商品恢复约 91.65%；目录中不同商品会有相同输入潜向量，加入实际前缀约束后的恢复另有口径，不能把任一恢复率当 NDCG 上限。

- 真实/打乱历史会改变输出，但生成排序收益弱且随噪声不同；MSE 好并不保证商品命中好。不能说完全没用历史。
- CF 改成教师商品向量作为 RQ 输入/重建目标；Hybrid 以内容为输入、在预训练中对齐 CF 教师，非简单拼接。两者**都有层内 Mixer**。
- 同时把监督改为去噪 MSE＋0.1×RQ 落地损失（路径 CE＋桶内 CE）；T 另有潜空间重建/VQ。旧软对齐项不应擅自加回来。预训练选点等也有变更，因此 CF 改善不能拆成“全是目标的功劳”或“全是新损失的功劳”。

## 8. 为什么补 AR、做了哪些修改、目前证据到哪

学长要求先看相同五件列表任务下传统 AR 的效果，判断新范式竞争力，然后研究 Mixer 适用范围。用户确定：**保留 DIGER 核心训练节奏，组内严格消融回答 Mixer，完整效果和训练过程回答方法竞争力。** 不强行改 DIGER 去匹配 CF 的更新节奏。

五组为 TIGER 无/有层内 Mixer、DIGER 无/有层内 Mixer、CF 无 Mixer；已有 CF 有 Mixer 作为对应参照。AR 每 session 展开五个条件任务，batch256，每等价 session epoch 13,857 次更新；CF 每 R 693 次。TIGER 预算 200,000 步；DIGER 用户后来截断最多35轮，但**仍沿用原120轮学习率轨迹及 patience15**，不是压缩调度到35轮。精确设计/配置/改动见 `docs/research/session_wise_ar_mixer/FIVE_ARM_DESIGN_20261113.md` 和 `IMPLEMENTATION.md`；运行代码 `scripts/session_wise_ar/`，配置 `configs/session_wise_ar/`。

## 11. 下一步讨论：有依据的方向与未批准的实验

1. **先完整判断新范式竞争力。** 等T1A现有验收材料齐全，按同协议看best、固定预算末点、整个曲线及训练成本。当前CF低于H0/TIGER/SASRec的差距明确，但哪一环造成差距尚未隔离。
2. **连续路线需区分三个环节。** 教师协同表→RQ潜空间是否丢了排序信息；去噪模型是否生成到正确商品附近；合法RQ路径/桶内决策是否再损失。已有NN、历史扰动、少步结果提供线索，不应绕回无止境小调参或已做过的诊断。若提出新监督或目标，先讲它针对哪个缺口，再明确唯一改动与对照。
3. **Mixer收益和训练稳定性分开。** 静态/冻结后有效不等于持续联合有效，旧H多seed收益也不等于L5O收益。可以讨论同父checkpoint冻结、保留小幅更新等，但要先确定新问题，不能看到坍缩就自动提交旧冻结方案。
4. **中频收益是值得追踪的现象。** 旧协议多路线有描述性一致性，但不是机制证明。L5O需要重新定义频次桶；可以讨论塌缩前同轮R17与后期的对照，避免只比较各自best造成混淆。
5. **可靠性。** 先把当前baseline/协议固定，再做有价值的seed重复；测试不选点，不按测试挑采样步数；单seed用户区间不能替代训练seed。不要将很多改动同时打包后声称单因素有效。

以上是待讨论方向，**均不构成新实验、统计或作业提交授权**。
