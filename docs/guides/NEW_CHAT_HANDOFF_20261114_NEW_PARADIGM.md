## 3. 当前新范式到底是什么

核心主线仍要保留：**根据用户历史，扩散生成连续商品向量，再经过RQ量化与目录约束落地成商品，逐件形成五商品列表**。用户不希望为了容易跑而随意删SID embedding、改变结构或改成纯离散AR；AR是竞争力参照。

### 3.1 商品侧

商品输入256维特征→RQ Encoder（256→512→256→128→32）→量化前潜向量z（32维）→四层残差量化（每层256中心、每中心32维）→四位SID及量化向量q。z是量化前向量，q是选中四个中心的和，不要混用。

RQ-VAE预训练有Encoder、Decoder与特征重建/VQ；选点后冻结RQ Encoder，保存固定z表。推荐联合训练不再使用RQ Decoder，改用潜空间量化重建和逐层VQ约束；Decoder预训练资产保留，不是说RQ-VAE从来不需要Decoder。

### 3.2 推荐侧

最多50件历史ID→查当前商品SID表→按码位查四张独立256维SID embedding→按商品和码位顺序展开，最长200个token→2层T5 Encoder。不是把32维q直接当历史embedding，也不是沿用H1的商品级MLP压缩。

真实历史Encoder在一次五商品生成中复用。第j件生成时：随机32维噪声→线性投影到256维→4层条件去噪Decoder读取历史及先前已生成商品的SID前缀，并使用扩散时间和列表位置条件→预测32维干净潜向量。训练随机抽噪声等级做单次去噪；推理20步DDIM迭代，不是训练连续做20步。噪声等级总数1000。

生成向量转换回原z尺度→逐层在合法目录前缀分支选择RQ码→最终SID桶内选z距离最近商品→排除已推荐商品→查所选商品SID加入后续前缀。不是全目录NN，也不是直接输出SID四分类。全目录NN只是已做的替代读出诊断。

共同结构宽256、4头、FFN1024；具体mask、尺度、损失归约、固定噪声和源代码绑定以设计/实现为准，勿凭本文概要改代码。

### 3.3 Mixer

B0无；B1同层256个中心间四头注意力；B2按RQ层块因果可见（当前层可以读当前及较早层，早层不读后层，非中心编号顺序因果）。独立SID embedding是推荐器参数，Mixer处理的是RQ码本中心，两者不是同一张表。

一层Mixer，无新增FFN/dropout；只有层身份，无中心编号标记；输出投影零初始化，初始有效中心=基础中心。输入LayerNorm后加层身份，得到修正D_l；以第1层为参考，乘stopgrad(RMS(C_l)/max(RMS(C_0),1e-8))后加回基础中心。该比例缩放不严格保证所有层相对修正相同，也不是后期0.1门控。

当下主对照优先层内交互，是候选选择，不是已证明跨层因果交互必然无效。

### 3.4 训练与文献参考的边界

CF：5个R epoch暖身，然后30块“10次T optimizer更新＋1个R epoch”，合计R35/T300。T不是完整目录epoch。R更新推荐器，T更新码本/Mixer，另一侧参数冻结但仍需保留对输入的梯度路径。RQ Encoder始终冻结，RQ Decoder不参加联合阶段；T块结束刷新SID/目录，R与评估用匹配版本。

R损失=去噪MSE＋0.1×RQ落地损失（路径CE＋桶内CE）；T再加权重1的潜空间重建和VQ。旧版软量化KL不再叠加。路径监督用真实SID前缀构造每层残差，合法目录内负平方距离作为logit；桶内损失监督真实商品。它是与RQ落地接口相适配的监督，不宣称等价于自由贪心生成风险。

参考来源：ETEGRec提供RQ/SID及协同商品表示的借鉴；DIGER gradient-fix提供可微量化及冻结RQ Encoder的联合训练参照；LETTER提供内容/协同对齐启发；SASRec风格教师提供协同商品表。整个“连续扩散＋RQ落地＋列表生成”组合是本项目设计，不冒充某篇论文的直接完整复现。具体链接、原设/适配/补全标注见正式设计文档；重新讨论论文原始实现时需核查原文/固定代码。

## 5. 为什么补传统AR、五组如何对照

学长要求先看TIGER式/DIGER式在相同session-wise任务下的表现，才能判断新范式竞争力及Mixer适用范围。不是要求所有方法使用同一训练节奏。

| 新实验 | 方法 | Mixer如何学习 |
|---|---|---|
| AR-T0 | TIGER式，无Mixer | 不适用 |
| AR-T1 | TIGER式，层内Mixer | 仅RQ预训练学习，推荐阶段完全冻结 |
| AR-D0 | DIGER gradient-fix，无Mixer | 逐batch联合更新码本 |
| AR-D1 | DIGER gradient-fix，层内Mixer | 预训练及逐batch联合更新 |
| CF-M0 | 当前纯协同扩散，无Mixer | 从预训练起去掉Mixer，其他设置保持CF-M1 |

另复用已有CF-M1，不是新训第六组。

AR用内容PCA256；CF用协同表。AR为3层RQ＋第4位消歧后缀（256槽），CF为4层真实RQ＋桶内连续向量消歧。AR商品间把已生成商品追加Encoder再编码，商品内SID token自回归；不加H1商品MLP。每件beam20，提交一件再生成下一件；不是一次top5，也不是整列表beam20。

AR batch256个条件任务，一条session展开5任务，所以每session等价轮13857次更新；CF batch1024个session，每R轮693次更新。原TIGER200000步≈14.43轮；DIGER每batch一次backward两个optimizer各step一次。不能为对齐CF把DIGER改成10T＋1R。

主比较：组内有/无Mixer严格消融；跨方法是完整方法竞争力比较，输入、网络、计算预算、选点机会不同，不是纯AR/扩散因果实验。

精确配置：`docs/research/session_wise_ar_mixer/FIVE_ARM_DESIGN_20261113.md`和`IMPLEMENTATION.md`。TIGER是按论文配置的本项目适配，未核实完整官方训练入口；DIGER固定作者gradient-fix提交ec0a9b51d02272be1935e1a6438cdc30bf9fadc1。不能把TIGER/DIGER称为结构配置完全相同、只差联合训练。

## 7. 接下来讨论优先级（不是新实验授权）

1. 先完成现有AR参照与CF冻结结果，分开看验证选best对应测试、实际final及过程曲线，不按测试重新选点。
2. CF已有单seedMixer正向结果，下一步值得问收益是否可重复、是否只是预训练空间差异、冻结后是否仍成立。多seed或拆预训练/联合阶段Mixer是候选，尚未授权。
3. 不因为T1失败和D1较差就断言所有码本交互无效；先区分优化/尺度/目录接口与方法问题。T1存在强预训练失稳，不能把失败当作干净的Mixer推荐性能对照。
4. CF本轮同时改变生成目标、监督、预训练选点，不能各自归因。若研究重点仍是Mixer，先把基线固定，再做有明确问题的最小消融，而非无止境调参。
