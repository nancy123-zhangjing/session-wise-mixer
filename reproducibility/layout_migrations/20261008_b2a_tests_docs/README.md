## 2. 怎样保护复现信息

- 移动前记录 717 份已有文件的哈希与五份完整性锁。
- 五份 `package_integrity.json` 只更新两个复现 helper 的哈希及测试路径/哈希；`files` 科学绑定部分不变，没有运行 `build` 或重新生成科学锁。
- 修改两个 helper 的 `seal` 路径生成方式，使新的测试目录能被正常绑定；其训练、分析、恢复逻辑不变。
- 六个模型测试及原日常隔离测试只移动；另五个测试只补充脚本导入路径、修正 legacy loader 定位。
- 源码 tar、初始化文件身份、SID hash、配置覆盖顺序、seed、结果数值均不变。当前整理提交不等于历史训练 runtime commit。
- A/B1 审计保留其历史状态，当前布局用 B2a 审计；不要为了让旧审计适配新路径而改写旧收据。
